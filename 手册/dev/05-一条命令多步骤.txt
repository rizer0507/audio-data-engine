一条命令多步骤（dev · 命令台账）
================================================================================
用途：专门收录「一条命令完成多步骤」的生产入口。分步排查仍看 01 / 00 / 单条流水线。
约定：每条只写最短可跑命令 + 前置 + 产物；细节链到 docs / 其它手册。
后续新增同类入口时，按下方模板追加一节即可（编号递增）。

环境（本节命令默认）：
  cd /data2/data-cp/lizi/audio-data-engine
  source /data2/data-cp/zk/env_hub/miniconda312_qw3tts/bin/activate
  export OMP_NUM_THREADS=1
  export MKL_NUM_THREADS=1
  export BATCH=<批次名>          # 与 --source-name / --batch 同一字符串
  export SOURCE_DIR=<原始音频根>
  export AUTHORIZED_GPUS=<授权卡号,逗号分隔>   # 禁止照抄历史卡号

================================================================================
1. 工序一全链路（030 · stage1 run）
================================================================================
# 目标：清洗 → 三族双跑 ASR → prepare/attach → 五类 v2.2 → export-summary
# 前置：configs/stage1/server.yaml 已补齐；authorized_gpus / engine_python /
#       families.qwen.vllm_bin / dnsmos.onnx_path；授权仅配置内 GPU
# 不做：用户不必手敲 prepare→attach→classify→export
# 详解：docs/07-操作手册/工序一单命令-服务器1000条试跑.md
#       docs/04-改进需求/已完成/030-工序一单命令编排与双GPU可靠执行.md
#       单条流水线执行命令.txt §0a

audio-data stage1 check-config --runtime-config configs/stage1/server.yaml

audio-data stage1 run \
  --batch "$BATCH" \
  --source "$SOURCE_DIR" \
  --model qwen=/data2/data-cp/zcl/models/Qwen3-ASR-1___7B \
  --model glm=/data2/data-cp/models/GLM-ASR-Nano-2512 \
  --model sensevoice=/data2/data-cp/xijujun/models/SenseVoiceSmall \
  --runtime-config configs/stage1/server.yaml \
  --gpus "$AUTHORIZED_GPUS"

audio-data stage1 status <job_id> --watch
audio-data stage1 wait <job_id>
# wait：reconcile.ok → exit 0；failed → 1；needs_attention → 3
# 本入口后台执行；SSH/VS Code 断开可继续（不必为 stage1 另开 tmux）

# 补跑：
# audio-data stage1 resume <job_id>
# audio-data stage1 retry <job_id> --family glm --run 2 --failed-only
# audio-data stage1 retry <job_id> --export-only

# 产物：
#   runs/stage1/jobs/<job_id>/
#   datasets/stage1/cleaned/cleaned_${BATCH}.parquet
#   datasets/stage1/asr/{qwen,glm,sensevoice}_{1,2}_asr_${BATCH}.parquet
#   datasets/stage1/derived/classified_five_class_v2_2_auto_noise_${BATCH}.parquet
#   data/exports/summary_five_class_v2_2_auto_noise_${BATCH}.xlsx

2. 工序一后置分类（031 · 六路 ASR 已齐）

# 目标：已有六路 ASR → audio_energy → dnsmos_v2_2_candidates → classify → 完整 XLSX
