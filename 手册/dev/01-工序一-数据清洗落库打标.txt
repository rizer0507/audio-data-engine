# 3b) 噪声打分（DNSMOS）— 工序说明与可选命令
# ---------------------------------------------------------------------------
# 落点：工序一③，ASR attach 之后；清洗①不跑 DNSMOS，也不引入 VAD。
# 主路径：分拣 YAML 内嵌 quality.asr_anomaly_noise（按需），读 configs/quality/dnsmos_p835.yaml。
# 旁路：pipelines/audio_quality_sidecar.yaml（全量，研究/复现 only）。
#
# 依赖（按需评分前检查）：
#   1) ONNX：configs/quality/dnsmos_p835.yaml → model_path（例 third_party/dnsmos/sig_bak_ovr.onnx）
#   2) pip：onnxruntime 或 pip install '.[dnsmos]'；内网可另装 distillmos（见 00 附录）
#   3) 音频：sample.audio.resampled_16k 在本机可读（路径在 /data2 时须在可读机跑）
#   4) calibrated: false（未听音校准禁止改 true；未校准不得自动定 environment_noise）
#
# 何时真正调用 DNSMOS（主路径）：
#   · selection_v3.0 / asr_anomaly：全族无有效转写，或任意成功路非中文话语
#   · selection_five_class_v1：外语/热词/提示词回声已前置排除，不因外语触发评分；
#     触发侧重全族无有效转写，以及空/有字+肯否、短应答冲突等（作旁证/送标，非定噪声类）
#   · 未触发 → not_required（分数保持 null，不能填干净分，不能挡金标）
#   · 触发失败 → failed/unsupported；不造 pending_evidence 池，五类下直接人工任务
#
# 状态字段：noise_diagnosis_status = not_required | pending | success | failed | unsupported
# 分数字段：dnsmos_sig / dnsmos_bak / dnsmos_ovrl；未校准 → noise_band=unknown
# 五类规则：低 DNSMOS / 全空 / VAD 未检出 均不能单独入 environment_noise；
#           需校准声学或人工听音回填（任务类型常为 verify_target_speech）
