单条流水线执行命令
=======================================================
用途：只维护「一条 pipeline run」命令；分片/并行/合并由 YAML sharding 自动完成。
改批次、改路径、改并行度：优先改对应 pipelines/*.yaml，再改本文件中的命令与备注。
执行顺序：1 → 2（工序②）→ 导出 xlsx（可选）。


-------------------------------------------------------
0. 进入工程（每次开终端先做）
-------------------------------------------------------
cd /workspace/audio-data-engine
source .venv/bin/activate
export OMP_NUM_THREADS=1
export MKL_NUM_THREADS=1


-------------------------------------------------------
1. 数据切片落库
-------------------------------------------------------
# YAML: pipelines/data_cleaning_source_A.yaml
# 输入: resources/manifest.yaml → source_A.path
# 输出: datasets/manifests/cleaned_source_A.parquet
# 并行: 改 YAML sharding.shards / parallel_shards / workers

audio-data pipeline run pipelines/data_cleaning_source_A.yaml

# 续跑（填入上次 runs/..._shards 目录）:
# audio-data pipeline run pipelines/data_cleaning_source_A.yaml --resume runs/<上次_shards目录>


-------------------------------------------------------
2. 多模型串行识别 + 编辑距离汇总（工序②，当前生产入口）
-------------------------------------------------------
# YAML: pipelines/multi_asr_aggregate.yaml
# 输入: datasets/manifests/cleaned_source_A.parquet
# 输出: datasets/manifests/multi_asr_aggregate_source_A.parquet
#       datasets/manifests/multi_asr_aggregate_source_A.jsonl
# 步骤: Qwen → 释放显存 → SenseVoice → 释放显存 → 纯文本清洗 → 相对基准(qwen)编辑距离
# 并行: 改 YAML sharding.gpus / instances_per_gpu / shards（样本分片并行，模型串行）
# 约束: shards == parallel_shards <= len(gpus) * instances_per_gpu
# 清洗: quality.normalize_transcripts（models / keep_raw）；去掉标签与标点
# 基准: pipeline 内 asr_edit_distance.params.baseline（默认 qwen）

export QWEN_ASR_MODEL_PATH="/home/lizi/Qwen3-ASR-main/data/outputs/0814-1506/checkpoint-1500"
export SENSEVOICE_MODEL_PATH=/data2/data-cp/xijujun/models/SenseVoiceSmall

audio-data pipeline run pipelines/multi_asr_aggregate.yaml

# 续跑:
# audio-data pipeline run pipelines/multi_asr_aggregate.yaml --resume runs/<上次_shards目录>


-------------------------------------------------------
2b. 导出 xlsx（parquet/jsonl 全量保留后按需转换）
-------------------------------------------------------
# <=50万行：一个 xlsx；>50万行：自动 stem-part-001.xlsx ...
python scripts/export_multi_asr_xlsx.py \
  --manifest datasets/manifests/multi_asr_aggregate_source_A.parquet \
  --output datasets/exports/multi_asr_aggregate_source_A.xlsx \
  --baseline qwen \
  --models qwen,sensevoice


-------------------------------------------------------
数据链（便于换批次时对照改名）
-------------------------------------------------------
source_A.path (wav/pcm)
  → cleaned_source_A.parquet
  → multi_asr_aggregate_source_A.parquet / .jsonl
  → (可选) datasets/exports/multi_asr_aggregate_source_A.xlsx


-------------------------------------------------------
换批次时改哪里（清单）
-------------------------------------------------------
[ ] resources/manifest.yaml                 # 新 source_id / path
[ ] pipelines/data_cleaning_*.yaml          # input.source、output.manifest、sharding
[ ] pipelines/multi_asr_aggregate.yaml      # input/output.manifest、gpus/shards、baseline
[ ] 本文件中的命令路径与 export 模型路径
