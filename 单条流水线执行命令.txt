单条流水线执行命令
=======================================================
用途：维护生产入口命令；分片/并行/合并由 YAML sharding 自动完成。
改批次：用 --source-name（+ 清洗时的 --source-dir），一般不用改 YAML 路径。
改并行度 / 卡号：改对应 pipelines/*.yaml 的 sharding。
分拣默认：工序一③ = classify_dataset_five_class_v2_2_auto_noise（029，影子验收前仍为正式）；
         后置入口默认 = classify_dataset_five_class_v2_4_on_demand_acoustic（037）；
         v2.3 legacy = classify_dataset_five_class_v2_3_min_acoustic（034）；
         028/v1 为对照；legacy = asr_anomaly + selection_v3.0。
执行顺序：1 清洗 → 2 ASR（≥3 族双跑 + register）→ 3 prepare/attach → energy/声学证据 → 五分类。
         噪声全量 sidecar 仅研究；聚合+字准（2d/2e）与 classify_dataset(v1) 仅为诊断 / legacy。
噪声速查：§2f-noise；正式五类入口：§2f-v3-029；v2.4 按需声学：§2f-v3-037；多标签：§2f-v3-040；v2.3：§2f-v3-034。
服务器过夜批跑：手工 vLLM / pipeline 必须进 tmux（见 手册/dev/00 §2.0）；
  Tabby/VS Code 不能保活。stage1 单命令（0a/030）本身后台跑，SSH 断开可继续。
