单条流水线执行命令
=======================================================
用途：维护生产入口命令；分片/并行/合并由 YAML sharding 自动完成。
改批次：用 --source-name（+ 清洗时的 --source-dir），一般不用改 YAML 路径。
改并行度 / 卡号：改对应 pipelines/*.yaml 的 sharding。
执行顺序：1 → 2a/2b（两个模型可独立执行）→ 2c 聚合 → 2d 字准率 → 导出 xlsx（可选）。


-------------------------------------------------------
0. 进入工程（每次开终端先做）
-------------------------------------------------------
cd /workspace/audio-data-engine
source .venv/bin/activate
export OMP_NUM_THREADS=1
export MKL_NUM_THREADS=1


-------------------------------------------------------
1. 数据切片落库
-------------------------------------------------------
# YAML: pipelines/data_cleaning_source_A.yaml
# 产物: datasets/manifests/cleaned_<source-name>.parquet|.jsonl

audio-data pipeline run pipelines/data_cleaning_source_A.yaml \
  --source-name test_local \
  --source-dir "D:\Work\audio-data-engine\数据集\wav-file"

# 续跑:
# audio-data pipeline run pipelines/data_cleaning_source_A.yaml \
#   --source-name mt3000 --source-dir /path/to/wav_or_pcm \
#   --resume runs/<上次_shards目录>


-------------------------------------------------------
2a. Qwen 独立识别
-------------------------------------------------------
# cleaned_<name> → qwen_asr_<name>
# 并行配置: pipelines/qwen_asr_batch.yaml 的 sharding
# 约束: shards == parallel_shards <= len(gpus) * instances_per_gpu

export QWEN_ASR_MODEL_PATH="/home/lizi/Qwen3-ASR-main/data/outputs/0814-1506/checkpoint-1500"
audio-data pipeline run pipelines/qwen_asr_batch.yaml --source-name test_local

# 续跑: 在命令末尾加 --resume runs/<上次_shards目录>


-------------------------------------------------------
2b. SenseVoice 独立识别（不依赖 Qwen）
-------------------------------------------------------
# cleaned_<name> → sensevoice_asr_<name>
# 并行配置: pipelines/sensevoice_asr_batch.yaml 的 sharding

export SENSEVOICE_MODEL_PATH=/data2/data-cp/xijujun/models/SenseVoiceSmall
audio-data pipeline run pipelines/sensevoice_asr_batch.yaml --source-name test_local

# Qwen 与 SenseVoice 只依赖 cleaned_<name>，可以分别执行，也可以同时在不同 GPU 上执行。


-------------------------------------------------------
2c. 按 id 聚合独立模型结果（不执行 ASR、不计算字准率）
-------------------------------------------------------
# qwen_asr_<name> + sensevoice_asr_<name> → multi_asr_aggregate_<name>
# --source-name 会同步改写 input/output 以及 manifests 中各模型的文件路径。
# 添加新模型时，在 pipelines/multi_asr_aggregate.yaml 的 manifests 中增加 model/path。

audio-data pipeline run pipelines/multi_asr_aggregate.yaml --source-name test_local

# 聚合会严格检查所有 manifest 的 id：重复、缺失或额外 id 都会立即报错。


-------------------------------------------------------
2d. 独立计算字准率 / 文本指标
-------------------------------------------------------
# multi_asr_aggregate_<name> → multi_asr_metrics_<name>
# Gold production 使用 configs/metrics/gold_agreement.yaml，指标语义为 agreement CER。

audio-data pipeline run pipelines/asr_metric_pipeline.yaml --source-name test_local

# 模型评测示例（reference=gold_text）:
# audio-data pipeline run pipelines/asr_eval.yaml \
#   --input-manifest datasets/manifests/asr_eval_test_local.parquet \
#   --output-manifest datasets/manifests/asr_eval_metrics_test_local.parquet


-------------------------------------------------------
2e. 导出 xlsx（parquet/jsonl 全量保留后按需转换）
-------------------------------------------------------
python scripts/export_multi_asr_xlsx.py \
  --manifest datasets/manifests/multi_asr_aggregate_mt3000.parquet \
  --output datasets/exports/multi_asr_aggregate_mt3000.xlsx \
  --baseline qwen \
  --models qwen,sensevoice


-------------------------------------------------------
数据链（source-name=mt3000 示例）
-------------------------------------------------------
--source-dir (wav/pcm)
  → cleaned_mt3000.parquet|.jsonl
  ├→ qwen_asr_mt3000.parquet
  └→ sensevoice_asr_mt3000.parquet
  → multi_asr_aggregate_mt3000.parquet / .jsonl
  → multi_asr_metrics_mt3000.parquet / .jsonl
  → (可选) datasets/exports/multi_asr_aggregate_mt3000.xlsx


-------------------------------------------------------
换批次时改哪里（清单）
-------------------------------------------------------
[ ] 命令中的 --source-name / --source-dir
[ ] （可选）pipelines/qwen_asr_batch.yaml、sensevoice_asr_batch.yaml 的 gpus/shards
[ ] 新增模型时，在 pipelines/multi_asr_aggregate.yaml 增加 model/path
[ ] 本文件中的模型环境变量
# 一般不再改 resources/manifest.yaml 与 YAML 内 input/output 路径


-------------------------------------------------------
可选：单独跑某一段（排障）
-------------------------------------------------------

# audio-data pipeline run pipelines/sensevoice_asr_batch.yaml --source-name mt3000
# audio-data pipeline run pipelines/multi_asr_aggregate.yaml --source-name mt3000
# audio-data pipeline run pipelines/asr_metric_pipeline.yaml --source-name mt3000
