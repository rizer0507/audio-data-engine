单条流水线执行命令
=======================================================
用途：维护生产入口命令；分片/并行/合并由 YAML sharding 自动完成。
改批次、改路径、改并行度：优先改对应 pipelines/*.yaml，再改本文件。
执行顺序：1 → 2（一条命令：全量 Qwen → 全量 SenseVoice+清洗打分）→ 导出 xlsx（可选）。


-------------------------------------------------------
0. 进入工程（每次开终端先做）
-------------------------------------------------------
cd /workspace/audio-data-engine
source .venv/bin/activate
export OMP_NUM_THREADS=1
export MKL_NUM_THREADS=1


-------------------------------------------------------
1. 数据切片落库
-------------------------------------------------------
# YAML: pipelines/data_cleaning_source_A.yaml
# 输入: resources/manifest.yaml → source_A.path
# 输出: datasets/manifests/cleaned_source_A.parquet

audio-data pipeline run pipelines/data_cleaning_source_A.yaml

# 续跑:
# audio-data pipeline run pipelines/data_cleaning_source_A.yaml --resume runs/<上次_shards目录>


-------------------------------------------------------
2. 多模型识别 + 清洗打分（工序②，一条命令）
-------------------------------------------------------
# YAML: pipelines/multi_asr_aggregate.yaml（stages 编排）
#   Stage1: pipelines/qwen_asr_batch.yaml
#           cleaned → qwen_asr_source_A.parquet
#   Stage2: pipelines/sensevoice_asr_batch.yaml
#           qwen_asr → multi_asr_aggregate_source_A.parquet/.jsonl
# 并行: 改两个 stage YAML 的 sharding（默认 2×4=8）
# 约束: shards == parallel_shards <= len(gpus) * instances_per_gpu

export QWEN_ASR_MODEL_PATH="/home/lizi/Qwen3-ASR-main/data/outputs/0814-1506/checkpoint-1500"
export SENSEVOICE_MODEL_PATH=/data2/data-cp/xijujun/models/SenseVoiceSmall

audio-data pipeline run pipelines/multi_asr_aggregate.yaml

# 续跑（填入上次打印的 *_stages 目录）:
# audio-data pipeline run pipelines/multi_asr_aggregate.yaml --resume runs/<上次_stages目录>


-------------------------------------------------------
2b. 导出 xlsx（parquet/jsonl 全量保留后按需转换）
-------------------------------------------------------
python scripts/export_multi_asr_xlsx.py \
  --manifest datasets/manifests/multi_asr_aggregate_source_A.parquet \
  --output datasets/exports/multi_asr_aggregate_source_A.xlsx \
  --baseline qwen \
  --models qwen,sensevoice


-------------------------------------------------------
数据链
-------------------------------------------------------
source_A.path (wav/pcm)
  → cleaned_source_A.parquet
  → qwen_asr_source_A.parquet          # stage1 中间产物
  → multi_asr_aggregate_source_A.parquet / .jsonl
  → (可选) datasets/exports/multi_asr_aggregate_source_A.xlsx


-------------------------------------------------------
换批次时改哪里（清单）
-------------------------------------------------------
[ ] resources/manifest.yaml
[ ] pipelines/data_cleaning_*.yaml
[ ] pipelines/qwen_asr_batch.yaml              # input/output、gpus/shards
[ ] pipelines/sensevoice_asr_batch.yaml        # input/output、gpus/shards、baseline
[ ] pipelines/multi_asr_aggregate.yaml         # stages 列表（一般不用改）
[ ] 本文件中的模型环境变量


-------------------------------------------------------
可选：单独跑某一段（排障）
-------------------------------------------------------
# audio-data pipeline run pipelines/qwen_asr_batch.yaml
# audio-data pipeline run pipelines/sensevoice_asr_batch.yaml
