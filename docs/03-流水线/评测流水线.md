# 评测流水线（工序三）

> 归属：**三大工序 · 工序三**。与工序二（训练）完全解耦。权威对齐见 [工序总览](../01-项目架构/工序总览.md)「两条数据入评测主路径」。

评测只依赖两样东西：

1. 已注册的评测集（含 `gold_text` / `type` / 音频键，id 唯一）
2. 各模型独立推理 Manifest（`--asr-run` 别名），与评测集 **按 id 对齐**

不依赖 Model Registry、不依赖工序二训练、不必一条 YAML 串行跑完。

```text
路径 A · 带金标外源
  清洗 → 多模型识别 → classify_external_gold（外源金标 + 分拣标签）
       → classified_* → 评测集 → 本流水线

路径 B · 不带金标
  清洗 → 多模型识别 → classify_dataset（共识匹配金标 + 分拣标签）
       → summary_ / gold_ / classified_* → 评测集 → 本流水线
```

两条在 `eval register` 之后命令相同。金标可信度升级（伪金标不得直接作正式评测真值）见 [011](../04-改进需求/进行中/011-数据挑选规则v2落地.md)。

## 路径 B：不带金标（工序一共识金标 → 评测）

```bash
# 1) 注册评测集（summary_ / gold_ / classified_）
audio-data eval register "datasets/stage1/derived/summary_${BATCH}.parquet" \
  --name "eval_${BATCH}"
audio-data eval check "eval_${BATCH}"

# 2) 各 vLLM 独立跑批（端口区分权重；同 family：base + 各 SFT）
#    若各实例 served-model-name 不同，再加：export QWEN_ASR_MODEL=<该实例名>
export QWEN_ASR_API_BASE=http://127.0.0.1:5561
audio-data pipeline run pipelines/qwen_asr_batch.yaml \
  --eval-name "eval_${BATCH}" --asr-run qwen-sft-epoch10

export QWEN_ASR_API_BASE=http://127.0.0.1:5562
audio-data pipeline run pipelines/qwen_asr_batch.yaml \
  --eval-name "eval_${BATCH}" --asr-run qwen-sft-epoch100

# 3) 以评测集为底表按 id 左连接（extra id 忽略；缺 id 失败）
#    若 summary 里已有原 qwen 文本，不要再 join 同名别名
audio-data pipeline run pipelines/eval_aggregate.yaml \
  --eval-name "eval_${BATCH}" \
  --join-manifest qwen-sft-epoch10 \
  --join-manifest qwen-sft-epoch100

# 4) 相对 gold_text 算多模型字准 + 按 type 导出
audio-data pipeline run pipelines/eval_metric_pipeline.yaml \
  --eval-name "eval_${BATCH}" \
  --eval-model qwen --eval-model qwen-sft-epoch10 --eval-model qwen-sft-epoch100
```

### 产物

**现行（Phase A + B）**

- `datasets/stage3/eval_sets/eval_${BATCH}.parquet`
- `datasets/stage3/asr/{alias}_asr_eval_${BATCH}.parquet`
- `datasets/stage3/derived/eval_aggregate_eval_${BATCH}.parquet`
- `datasets/stage3/derived/eval_metrics_eval_${BATCH}.parquet`
- `datasets/stage3/reports/{eval_name}/evaluation.{json,xlsx}`（权威）
- `runs/.../reports/evaluation.{json,xlsx}`（副本；无 `--eval-name` 时仍为唯一落点）

旧扁平 `datasets/manifests/` 下的同名文件仍可被解析（双读）。详见 [009](../04-改进需求/进行中/009-datasets模块改造需求.md)。

```bash
python scripts/run_eval_from_summary.py \

  --model qwen-sft-e10=datasets/stage1/asr/qwen-sft-e10_asr_....parquet \
```

## 路径 A：带金标外源（xlsx → classified_ → 评测）

**正式路径（工序一 B2，已落地）**：

```bash
# 前置：清洗 + 同 family ASR（--asr-run 与 --aggregate-base 一致）
audio-data pipeline run pipelines/classify_external_gold.yaml \
  --source-name "$BATCH" \
  --aggregate-base qwen3-asr \
  --external-gold path/to/外源金标.xlsx \
  --label-col label_text_raw \
  --force

audio-data eval register "datasets/stage1/derived/classified_${BATCH}.parquet" \
  --name "eval_${BATCH}"
# 其后与路径 B 相同：独立跑批 / eval_aggregate / eval_metric_pipeline
```

说明：`gold_text` 来自 xlsx；`type` 为 `external_gold_v1` 四桶；详解 [006](../04-改进需求/已完成/006-工序一清洗引擎拆分需求.md)。

**临时旁路（过渡，启动会 WARN；新任务请用正式路径）**：

```bash
python scripts/run_eval_from_label_xlsx.py \
  --label-xlsx path/to/外源金标.xlsx \
  --label-col label_text_raw \
  --base-model qwen3-asr=datasets/stage1/asr/qwen3-asr_asr_${BATCH}.parquet \
  --model qwen3-asr-sft-e10=datasets/stage1/asr/qwen3-asr-sft-e10_asr_${BATCH}.parquet \
  --eval-name eval_external_${BATCH} \
  --force
```

更薄的只算 CER：`scripts/eval_external_baseline_cer.py`（[外源基线字准率脚本](../07-操作手册/外源基线字准率脚本.md)）。

评测侧说明见 [005](../04-改进需求/已完成/005-评测流水线改进需求.md)。
