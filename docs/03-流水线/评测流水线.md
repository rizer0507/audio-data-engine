# 评测流水线（工序三）

> 归属：**三大工序 · 工序三**。与工序二（训练）完全解耦。权威对齐见 [工序总览](../01-项目架构/工序总览.md)「两条数据入评测主路径」。

评测只依赖两样东西：

1. 已注册的评测集（含 `gold_text` / `type` / 音频键，id 唯一；正式集须 `label_tier=gold` 或人审/外源可信）
2. 各模型独立推理 Manifest（`--asr-run` 别名），与评测集 **按 id 对齐**

不依赖 Model Registry、不依赖工序二训练、不必一条 YAML 串行跑完。

```text
路径 A · 带金标外源
  清洗 → 多模型识别 → classify_external_gold（外源金标 + 分拣标签）
       → classified_* → 评测集 → 本流水线

路径 B · 不带金标（现行默认 v3）
  清洗 → 多模型识别（N≥3×双跑 + register）→ prepare/attach/sidecar → classify_dataset_v3
       → 人审升真金标 / 冻结 eval_core|eval_random Release
       → 评测集 → 本流水线

  （legacy）classify_dataset / classify_dataset_v2 仅复现，不作新批次默认
```

两条在 `eval register` 之后命令相同。

**金标准入（selection_v2 / 正式评测）**：默认 `eval register --formal` 拒绝 `pseudo_gold_*` / `auto_gold` / `consensus_gold`；调试须 `--allow-pseudo-gold`（`eval_trust=pseudo_debug`）或过渡 `--legacy`。见 [011](../04-改进需求/已完成/011-数据挑选规则v2落地.md)。

## 路径 B：正式评测（人审 / 冻结 Release）

```bash
# 1) 注册评测集（推荐：冻结的 eval_core_vNNN / eval_random_vNNN，或 reviewed_ 人审结果）
#    不要把 export-gold 的伪金标直接当正式评测真值
audio-data eval register "datasets/stage1/derived/reviewed_${BATCH}.parquet" \
  --name "eval_core_v001"
audio-data eval check "eval_core_v001" --formal --train-dataset "train_${BATCH}"

# 调试连通性（产物不得冒充正式报告）：
# audio-data eval register "datasets/stage1/derived/summary_${BATCH}.parquet" \
#   --name "eval_debug_${BATCH}" --allow-pseudo-gold

# 2) 各 vLLM 独立跑批（端口区分权重；同 family：base + 各 SFT）
export QWEN_ASR_API_BASE=http://127.0.0.1:5561
audio-data pipeline run pipelines/qwen_asr_batch.yaml \
  --eval-name "eval_core_v001" --asr-run qwen-sft-epoch10

export QWEN_ASR_API_BASE=http://127.0.0.1:5562
audio-data pipeline run pipelines/qwen_asr_batch.yaml \
  --eval-name "eval_core_v001" --asr-run qwen-sft-epoch100

# 评 Kimi-vLLM 本身：同一条专属流水线（内部 pad），评测集音频仍是 resampled_16k
# export KIMI_ASR_API_BASE=http://127.0.0.1:5554,http://127.0.0.1:5555
# audio-data pipeline run pipelines/kimi_asr_batch.yaml \
#   --eval-name "eval_core_v001" --asr-run kimi

# 评 GLM-vLLM 本身：同一条专属流水线（无 pad），端口不要和 Qwen/Kimi 冲突
# export GLM_ASR_API_BASE=http://127.0.0.1:5570
# export GLM_ASR_MODEL=glm-asr
# audio-data pipeline run pipelines/glm_asr_batch.yaml \
#   --eval-name "eval_core_v001" --asr-run glm

# 3) 以评测集为底表按 id 左连接
audio-data pipeline run pipelines/eval_aggregate.yaml \
  --eval-name "eval_core_v001" \
  --join-manifest qwen-sft-epoch10 \
  --join-manifest qwen-sft-epoch100

# 4) 相对 gold_text 算多模型字准 + 业务风险指标 + 按 type/subtype 导出
#    空标桶（true_silence 等）从主 CER 剔除
#    business_metrics_v1：NFR/FAR/NAHR/FAER/NSHR/肯定保留率等写入 evaluation.json
#    缺校准门禁阈值 → publish_status=needs_review（不自动 pass）
audio-data pipeline run pipelines/eval_metric_pipeline.yaml \
  --eval-name "eval_core_v001" \
  --eval-model qwen --eval-model qwen-sft-epoch10 --eval-model qwen-sft-epoch100
```

- `runs/.../reports/evaluation.{json,xlsx}`（副本）

### v3 业务指标与生产切换门禁（012-E）

- 配置：`configs/metrics/business_risk_v1.yaml`（与 CER 共用 `MetricRunner`，禁止旁路脚本另实现一套）
- 每个指标输出 `numerator/denominator/value/eligible_count/excluded_count`；分母 0 → `value=null`
- 固定评测集上任一模型 `failed/missing` → `publish_status=incomplete`
- 缺 `min_improvement` / 非劣容忍度或分母不足 → `needs_review`
- **分拣默认已切 v3（014）**；本门禁只阻塞「业务回归 pass / 自动发布」，不阻塞 `classify_dataset_v3`
- 细则：[012-E](../04-改进需求/已完成/012-E-业务评测与生产切换.md)（操作口径被 014 覆盖）

## 路径 A：带金标外源（xlsx → classified_ → 评测）

**正式路径（工序一 B2，已落地）**：

```bash
audio-data pipeline run pipelines/classify_external_gold.yaml \
  --source-name "$BATCH" \
  --aggregate-base qwen3-asr \
  --external-gold path/to/外源金标.xlsx \
  --label-col label_text_raw \
  --force

audio-data eval register "datasets/stage1/derived/classified_${BATCH}.parquet" \
  --name "eval_${BATCH}"
# 其后与路径 B 相同：独立跑批 / eval_aggregate / eval_metric_pipeline
```

说明：`gold_text` 来自 xlsx（`label_source=external` / `label_tier=gold`）；`type` 为 `external_gold_v1` 四桶；详解 [006](../04-改进需求/已完成/006-工序一清洗引擎拆分需求.md)。

**临时旁路（过渡，启动会 WARN；新任务请用正式路径）**：

```bash
python scripts/run_eval_from_label_xlsx.py \
  --label-xlsx path/to/外源金标.xlsx \
  --label-col label_text_raw \
  --base-model qwen3-asr=datasets/stage1/asr/qwen3-asr_asr_${BATCH}.parquet \
  --model qwen3-asr-sft-e10=datasets/stage1/asr/qwen3-asr-sft-e10_asr_${BATCH}.parquet \
  --eval-name eval_external_${BATCH} \
  --force
```

更薄的只算 CER：`scripts/eval_external_baseline_cer.py`（[外源基线字准率脚本](../07-操作手册/外源基线字准率脚本.md)）。
