关于评测流水线：在金标/汇总评测集上对比多个模型阶段的字准（已解耦落地）

推荐入口（与训练无依赖）：
1. `audio-data eval register <summary|gold> --name eval_$BATCH`
2. `qwen_asr_batch --eval-name eval_$BATCH --asr-run <alias>`（各 vLLM 独立跑批）
3. `eval_aggregate --eval-name ... --join-manifest ...`（按 id 对齐）
4. `eval_metric_pipeline --eval-name ... --eval-model ...`（vs gold + 按 type 导出）

兼容旧入口：
- `pipelines/evaluate_registered_models.yaml`（Registry + 双端口串行，仍耦合）
- `pipelines/asr_eval.yaml`（已有文本时只算字准；可用 `--eval-name`）

手册：`全自动训练评测闭环执行手册-local.txt` / `-dev.txt` 第四节

设计说明：`docs/流水线改进/评测流水线(解耦).md`

评测保证：
1. 先检查金标覆盖；允许无金标，只统计有金标部分，并在 gold_coverage / xlsx 中注明
2. id 必须唯一，重复直接失败；aggregate 可 left-join（忽略推理侧 extra id）
3. 识别结果复用同款清洗（normalize_transcripts + blank_exact_eval_v1，`models: ["*"]`）
4. 导出 evaluation.xlsx（结果 / 统计摘要 / 按type统计），每个 `--eval-model` 一列字准率
