# 改造①：同源任意 ASR 结果聚拢 + base 严格一致金标（已落地）

## 需求澄清
1. **不是“双跑专用”**：同一 `--source-name` 下可尽情使用任意模型/任意批次；只要结果落盘即可聚拢。
2. **结果可区分**：用 `--asr-run <alias>`（如 qwen1、qwen2、sensevoice1）写不同 Manifest / transcript 键；source 不变。
3. **字准**：指定 base（如 qwen1），其余结果对比 base 算 agreement CER。
4. **金标**：必须**完全一致**（`max_vs_base_agreement_cer == 0`）才进 auto_gold；金标文本取 base。有一字差不能自动进金标列。

## 落地入口
- ASR：`--source-name $BATCH --asr-run qwen1`
- 聚合：`--aggregate-base qwen1 --join-manifest qwen2 --join-manifest sensevoice1 ...`
- 字准：`--agreement-base qwen1`（`configs/metrics/gold_agreement.yaml` 的 `vs_base`）
- 分拣：`configs/selection/zh_asr_v1.yaml`（`selection_zh_asr_v1_5`；CER≤0.10 进金标；语音信箱正则→voicemail）
