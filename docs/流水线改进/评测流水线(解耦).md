## 落地（与训练完全解耦）

评测只依赖两样东西：
1. 已注册的评测集（含 `gold_text` / `type` / `resampled_16k`，id 唯一）
2. 各模型独立推理 Manifest（`--asr-run` 别名），与评测集 **按 id 对齐**

不依赖 Model Registry、不依赖工序④训练、不必一条 YAML 串行跑完。

### 命令链

```bash
# 1) 注册评测集（通常用工序③的 summary_ / gold_）
audio-data eval register "datasets/manifests/summary_${BATCH}.parquet" \
  --name "eval_${BATCH}"
audio-data eval check "eval_${BATCH}"

# 2) 各 vLLM 独立跑批（端口区分权重；served-model-name 可同为 qwen3-asr）
export QWEN_ASR_API_BASE=http://127.0.0.1:5561
audio-data pipeline run pipelines/qwen_asr_batch.yaml \
  --eval-name "eval_${BATCH}" --asr-run qwen-sft-epoch10

export QWEN_ASR_API_BASE=http://127.0.0.1:5562
audio-data pipeline run pipelines/qwen_asr_batch.yaml \
  --eval-name "eval_${BATCH}" --asr-run qwen-sft-epoch100

# 3) 以评测集为底表按 id 左连接（extra id 忽略；缺 id 失败）
#    若 summary 里已有原 qwen 文本，不要再 join 同名别名
audio-data pipeline run pipelines/eval_aggregate.yaml \
  --eval-name "eval_${BATCH}" \
  --join-manifest qwen-sft-epoch10 \
  --join-manifest qwen-sft-epoch100

# 4) 相对 gold_text 算多模型字准 + 按 type 导出
audio-data pipeline run pipelines/eval_metric_pipeline.yaml \
  --eval-name "eval_${BATCH}" \
  --eval-model qwen --eval-model qwen-sft-epoch10 --eval-model qwen-sft-epoch100
```

### 产物

- `datasets/manifests/eval_${BATCH}.parquet`
- `datasets/manifests/{alias}_asr_eval_${BATCH}.parquet`
- `datasets/manifests/eval_aggregate_eval_${BATCH}.parquet`
- `datasets/manifests/eval_metrics_eval_${BATCH}.parquet`
- `runs/.../reports/evaluation.json` + `evaluation.xlsx`
  （结果 / 统计摘要 / 按type统计；每个 `--eval-model` 一列字准率）

### 实现入口

- CLI：`audio-data eval register` / `eval check`；`pipeline run --eval-name` / `--eval-model`
- 流水线：`eval_aggregate.yaml`、`eval_metric_pipeline.yaml`（复用 `qwen_asr_batch.yaml` 做推理）
- 配置：`configs/metrics/model_eval.yaml`（`vs_gold`）；`blank_exact_eval_v1.yaml`（`models: ["*"]`）
- 兼容旧入口：`evaluate_registered_models.yaml`（仍耦合 Registry + 双端口串行）
