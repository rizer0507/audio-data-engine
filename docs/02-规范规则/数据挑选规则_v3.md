## 1. 目标

在工序一「清洗 + 全量 ASR + 转写清洗」完成后，对有效样本做互斥五类分拣：

```text
voicemail / semantic_risk / environment_noise / gold_candidate / hardcase
```

核心原则：

1. **先 ASR 预分流，再按需声学**——不全量默认跑 Silero / energy / DNSMOS / EfficientAT。  
2. **EfficientAT 退出默认主路径**。  
3. **DNSMOS 仅服务疑似 Qwen 幻觉与人声噪声**；分类只用 SIG；BAK/OVRL 可存不设门槛。  
4. **静默 = 混合前严格全零**；禁止用 inaudible / 低能量阈值冒充。  
5. **缺失不补票**；失败记 status/errors，不伪造成功证据。

---

## 2. 在工序中的位置

```text
音频清洗（剔除物理无效 / 零时长）
  → 全量 ASR（配置家族 × 双跑；当前工程默认三族六路）
  → 转写结果清洗（保留原始 / 最终 / 成功态 / 清空原因）
  → 【本规范】五类 v3 分拣
       语音信箱 → ASR 预分流 A—E → 按需 Silero
       → 按需严格全零 energy → 按需 DNSMOS(SIG) → 五类汇总
  → export-summary / 可选人审 / 训练汇总
```

编排（正式 pipeline / 后置入口同一实现）：

```text
quality.asr_route_v2_4
  → quality.silero_vad_candidates → quality.silero_vad（respect_candidates）
  → quality.audio_energy_candidates → quality.audio_energy（严格全零）
  → quality.dnsmos_v2_4_candidates
  → quality.classify（rule_version=selection_five_class_v3）
```

`stage1 run` 内嵌 classify 与后置 `stage1 classify` **均默认本规范**。

## 3. 口径摘要

| 概念 | 定义 |
| --- | --- |
| 稳定有字 | 同族双跑成功，清洗后非空文本一致 |
| 稳定否定票 | 同族双跑成功且最终均为空；原生空或规则清洗空均计票，每族 1 票 |
| 原生稳定空 | 双跑成功且**原始**输出均为空（未经回声/超长置空） |
| 发生过转写 | 看清洗前原始输出 |
| 否定票 | 看清洗后最终输出 |
| 家族映射 | 简版「四族/八路」= **配置中的全部家族 × 双跑**；当前默认三族六路，须在 `decision_evidence.configured_families` 写清 |

## 4. 判定顺序（命中即结束）

完整条文见简版 0922。摘要：

1. 任一路**原始**命中语音信箱 → `voicemail`  
2. 全家族双跑成功 + Qwen≥1 次原始有字 + 其他家族最终均空 + Silero 有人声 + **SIG 低** → `semantic_risk:qwen_hallucination_suspected`  
3. 全家族双跑成功 + 全部路次原始均空 + Silero 有人声 + **SIG 低** → `environment_noise:human_noise`  
4. 任一家族双跑不稳定（且未命中 2）→ `hardcase`  
5. ≥2 稳定有字 + 极性对立 + 无否定票 + Silero 有人声 → `semantic_risk:polarity_conflict`  
6. ≥2 稳定有字 + 关键短应答实质歧义（未构成 5）+ 无否定票 + Silero 有人声 → `semantic_risk:critical_polarity_response`  
7a. 全部原生稳定空 + Silero 无人声 + **全声道严格全零** → `environment_noise:silence`  
7b. 全部原生稳定空 + Silero 无人声 + 至少一声道非零 → `environment_noise:background_suspected`  
8. ≥2 稳定同文 + 其余有效非空同文 + 无否定票 + Silero 有人声 → `gold_candidate`  
9. 其余 → `hardcase`

硬约束：

- 第 2 条须在「不稳定 → hardcase」之前提取（队列 A）。  
- SIG 低沿用 `dnsmos_decision_v2_2` 的 `weak_sig`；缺失/非低档 → hardcase，不猜阈值。  
- 一致输出「不要」等名单内容**不**触发第 6 条，可走 gold。

## 5. 按需声学计算顺序

完整步骤见 [分类执行流程(按需声学0922)](./分类执行流程(按需声学0922).txt)。

```text
语音信箱结束 → 不跑声学
A—E 才跑 Silero
仅 B∩无人声 → energy（严格全零）
仅 (A∪B)∩有人声 → DNSMOS(SIG)
C/D/E 有人声后直接出类，不跑 energy/DNSMOS
```

未入选样本声学状态须为 `not_required`（或等价），不得写成假证据。

## 6. 噪声子类与守恒

| `noise_kind` | 含义 |
| --- | --- |
| `silence` | 静默噪声（严格全零） |
| `background_suspected` | 非静默背景噪声 |
| `human_noise` | 人声噪声 |

```text
分类输入总量 = 五类数量之和
噪声主类数量 = silence + background_suspected + human_noise
前置剔除的无效音频另计（不进五类分母）
```

## 7. 产物与命令

```bash
# 后置入口（推荐）
python scripts/classify_asr_to_xlsx.py --batch "$BATCH" --energy-workers 32
audio-data stage1 classify --batch "$BATCH" --energy-workers 32

# 正式 pipeline
audio-data pipeline run pipelines/classify_dataset_five_class_v3.yaml \
  --source-name "$BATCH" \
  --config configs/selection/zh_asr_five_class_v3.yaml \
  --force
```

| 产物 | 路径 |

| XLSX | `data/exports/summary_five_class_v3_${BATCH}.xlsx` |
| parquet | `datasets/stage1/derived/classified_five_class_v3_${BATCH}.parquet` |

| `--rule-version` | 说明 |
| --- | --- |
