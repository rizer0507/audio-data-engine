## 输入契约（硬）

1. **族数** `N ≥ 3`；每族恰好 **2** 跑；总路数 **2N**。
2. `teacher_families` = 非 `target_family` 的已配置族（共 N−1）。
3. 别名 / `transcript_key` 须在配置中显式声明；禁止仅靠文件名猜测归族。
4. `attach_asr_v3` 前须 `prepare` 冻结 reservation，且各族 run 已 catalog register。
5. 缺声明族或路数不符 → **fail-fast**，不得静默降到 v1。

## 分拣要点

- 引擎：`consensus_v3` / `selection_v3.0`（`core/selection_v3/`）。
- 同族双跑最多计一票；全量共识相对**配置内全部 N 族**，不是写死「四族」。
- 相似度阈值见 YAML（家族内 / teacher / pseudo_high 等，常见 0.98）。
- DNSMOS：`calibrated: false` 时可分拣与送审；**禁止**把 unknown/noisy 自动放行进伪标签训练集。
- 伪高置信（`pseudo_high`）仍非 formal eval 真值；须人审或外源金标。
- 产物只写 `classified_v3_*`，不覆盖历史 `classified_*` / `classified_v2_*`。
