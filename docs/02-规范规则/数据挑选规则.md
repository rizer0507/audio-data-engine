## 配置入口

- 策略文件：`configs/selection/zh_asr_v1.yaml`
- 语音信箱正则：`configs/selection/voicemail_patterns_v1.yaml`
- 分拣算子：`classify_dataset` / `quality.classify`

## 三个字段拆开

| 字段 | 含义 | 取值示例 |
| --- | --- | --- |
| `type` | 这条数据是什么问题 | `auto_gold` / `consensus_gold` / `hardcase` / … |
| `decision` | 最终怎么处理 | `auto_accept` / `auto_empty` / `model_review` / `manual_review` |
| `label` / `gold_text` | 最终金标文本 | 非空字符串或空 |

另写入审计字段：`rule_version`、`selected_model`、`support_models`、`support_count`、`support_family_count`、`consensus_score`、`min_similarity`、`semantic_qwen`、`semantic_sensevoice`、`review_reason` 等。

## 核心概念

### transcript_similarity（不是「字准率」）

挑选阶段没有人工金标，模型两两比较得到的是**转写一致度**：

```text
similarity(A, B) = 1 - edit_distance(A, B) / max(len(A), len(B))
```

正式阈值：

| 常量 | 默认 | 含义 |
| --- | --- | --- |
| `STRICT_THRESHOLD` | 0.95 | 高度一致 → `auto_gold` / voicemail 严格自动金标 |
| `CONSENSUS_THRESHOLD` | 0.90 | 多数派 cluster 内部一致门槛 |

### 模型族（model_family）

同族多跑不算独立票：`qwen1+qwen2` 只算 Qwen family。默认族映射见配置 `model_families`。

### 金标选取：medoid（禁止随机）

在候选转写中选与其余文本平均 similarity 最高者；并列时按 `model` 名字典序稳定打破。

## 判定顺序（严格）

```text
文本标准化
  → 损坏/时长≤0 或全部为空？ → noise (auto_empty)
  → ≥2 模型族命中 voicemail？ → voicemail
  → 主/次族 positive↔negative 冲突？ → semantic_inversion
  → 主族全空且其他非空？ → qwen_missing
  → 空占比≥75% 且非空仅单族？ → hallucination
  → 全部非空且 min_pairwise≥0.95 且语义一致？ → auto_gold
  → ≥75% dominant cluster（内部≥0.90、跨≥2 族、语义一致）？ → consensus_gold
  → hardcase
```

## 分拣桶

| 优先级 | type | 核心含义 | 典型 decision |
| ---: | --- | --- | --- |
| 1 | `noise` | 损坏/无效，或全部模型为空 | `auto_empty`，label 空 |
| 2 | `voicemail` | ≥2 模型族命中语音信箱正则 | 一致则 `auto_accept`，否则 `manual_review` |
| 3 | `semantic_inversion` | 模型族间肯定/否定冲突 | 默认 `model_review`；≥2 独立族多数可 `auto_accept` |
| 4 | `hallucination` | 空占多数且非空仅来自单族 | 通常 `model_review`；≥3 族且其余皆空可 `auto_empty` |
| 5 | `qwen_missing` | 主族（默认 Qwen）全空、其他非空 | `model_review` |
| 6 | `auto_gold` | 全部非空且高度一致 | `auto_accept` + medoid |
| 7 | `consensus_gold` | 明显多数派跨族一致 | `auto_accept` + cluster medoid |
| 8 | `hardcase` | 无法形成可靠共识 | `model_review` |

兼容说明：旧桶名 `review_queue` 仅保留在 expr 遗留模式与 CLI 人审默认列表中；现行引擎输出 `qwen_missing`。

## 工序衔接

- `audio-data review export-gold`：默认导出 `auto_gold` + `consensus_gold`（且 `decision=auto_accept`）
- `audio-data review export`：默认导出待审桶（`qwen_missing` / `hardcase` / `hallucination` / `semantic_inversion` / `review_queue`）
- 人审可搁置；`--allow-unresolved-review` 允许仅用已有金标冻结 Release

## 遗留模式

若配置显式提供 `rules:` 且未设 `engine: consensus_v1`，仍走旧版 pandas `expr` 有序规则（单测与兼容用）。**现行生产配置使用 consensus 引擎。**
