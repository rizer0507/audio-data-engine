判定证据组合 → 最终分类（0922修订版）

口径：
- 分类输入已剔除物理无效、零时长音频；按下列顺序判定，命中即结束。
- 稳定有字 = 同一家族双跑成功，清洗后的非空文本一致。
- 稳定否定票 = 同一家族双跑成功且最终均为空；原生空、可信规则清洗空均计票，每族只计1票。
- 原生稳定空 = 同一家族双跑成功，模型原始输出均为空，没有经过回声/超长等置空处理。
- “发生过转写”看清洗前原始输出；“否定票”看清洗后最终输出，分别记录。
- 分歧仅指有效非空文本的实质语义差异；格式差异不算，空/失败/缺失本身不算语义歧义。
- 保留至少2家族稳定同文的已验证共识逻辑，不考虑多家族稳定同错的极端情况。
- 缺失不补票；普通gold及极性风险至少需要2家族稳定证据。语音信箱和第2条疑似Qwen幻觉按各自条件判定。

1、任一路原始转写命中语音信箱关键词 + 其他证据任意
   → 语音信箱

2、四家族双跑全部成功 + Qwen至少一次原始输出非空 + 其他3家族双跑最终均为空 + Silero VAD有人声 + SIG低 + BAK任意
   → semantic_risk：qwen_hallucination_suspected（疑似Qwen幻觉）

3、四家族双跑全部成功且八路原始输出均为空 + Silero VAD有人声 + SIG低 + BAK任意
   → 噪声：human_noise（人声噪声）

4、任一家族双跑不稳定（两文不同、一空一文、仅一次成功） + 未命中前述组合
   → hardcase

5、至少2个家族稳定有字 + 对同一命题表达明确相反含义 + 没有任何否定票 + Silero VAD有人声 + SIG/BAK任意
   → semantic_risk：polarity_conflict（极性冲突）

6、至少2个家族稳定有字 + 文本存在涉及关键短应答含义的实质歧义 + 相关输出命中名单 + 未构成第5条明确对立 + 没有任何否定票 + Silero VAD有人声 + SIG/BAK任意
   → semantic_risk：critical_polarity_response（关键极性短应答歧义）

7a、四个家族双跑全部为原生稳定空 + Silero VAD无人声 + 全声道全部采样值为0 + SIG/BAK任意
    → 噪声：silence（静默噪声）

7b、四个家族双跑全部为原生稳定空 + Silero VAD无人声 + 至少一个声道存在非零采样值 + SIG/BAK任意
    → 噪声：background_suspected（非静默背景噪声）

8、至少2个家族稳定同文 + 其余有效非空文本全部同文 + 没有任何否定票 + Silero VAD有人声 + SIG/BAK任意
   → gold

9、以上全部未命中
   → hardcase

执行说明：
- audio_energy仅对“四家族原生稳定空 + Silero VAD无人声”子集按需计算，用于第7a/7b条细分；其他分支不计算。
- 静默判据使用混合声道前的严格全零检查，不使用inaudible或低能量阈值代替。非零不等于嘈杂，因此使用“非静默背景噪声”名称。
- 现有audio_energy需补充严格全零标记；检查失败或结果缺失时归hardcase，不猜子类。噪声子类包含silence、background_suspected、human_noise，主类总量不重复计数。
- 第2/3条直接进入对应主类，不再作为hardcase候选标签；语音信箱仍优先。
- 第2条的其他3家族按既定否定票口径判断：原生空或规则清洗空均可，失败/缺失不可。Qwen原始有字后被清洗为空，仍算发生过转写。
- 第2条不要求Qwen双跑同文；只要双跑都成功且至少一次原始有字即可，因此放在通用不稳定兜底之前。
- 第3条要求八路原始全空，清洗后才为空的情况不能冒充“均未发生转写”；第2/3条互斥。
- SIG低沿用配置中的低档定义，不在本文新增数值阈值；SIG缺失或不在低档不能命中第2/3条。BAK不设门槛。
- 一致输出“不要”等名单内容不触发第6条，满足第8条即可为gold。
- 每路保留原始文本、最终文本及清空原因；“疑似Qwen幻觉”是风险分类，不表示已确认其正确训练标签为空。
