本规范是当前生产挑选口径。旧 v2.0 / v3.0 挑选规则文档已废止，不再作为业务依据。

---

## 1. 目标

复用已有多家族 ASR：先排除外语、热词全文回声、模型提示词全文回声，再将有效样本严格分入五个业务类别；定不了类的样本立即生成可执行人工标注任务。

不设「待处理 / 待补证据 / pending_evidence」业务出口。不重跑 GPU ASR，不改写原始转写，不覆盖历史人标与 release。

---

## 2. 三个样本出口（互斥守恒）

```text
输入数 = excluded + classified + manual_annotation
```

| 出口 | 含义 |
| --- | --- |
| `excluded` | 全部配置路次被前置排除；不进五类，不建人工任务 |
| `classified` | 已赋予下列五类之一；可附带抽查/标注任务 |
| `manual_annotation` | 未自动定类，但已创建可执行人工任务（允许 `category=null`，禁止裸 null） |

---

## 3. 五个业务类别

| 类别 | 一句话 |
| --- | --- |
| `voicemail` | 有效路次命中语音信箱/电话助手等正则 |
| `gold_candidate` | ≥3 合格稳定族高一致，可抽查接纳 |
| `semantic_risk` | 仅三种严格子类（见 §6） |
| `hardcase` | 多族实质高分歧，非兜底筐 |
| `environment_noise` | 有校准/人工声学依据的环境噪声或串音 |

---

## 4. 强制执行顺序

```text
ASR 聚合与身份检查
  → 逐路前置排除（外语 / 热词全文回声 / 提示词全文回声）
  → 全路排除？→ excluded，结束
  → 任意有效路信箱命中？→ voicemail，结束
  → 家族证据 + 按需声学诊断（失败不等待）
  → semantic_risk：②幻觉 → ③短音频不可辨 → ①反转
  → environment_noise（已确认）
  → gold_candidate
  → hardcase
  → 其余 → manual_annotation
```

前置排除与信箱完成前，不得触发噪声评分或其他类别。排除路次只读审计，不参与投票、信箱、风险、选文。

---

## 5. 逐路前置排除

| 原因 | 条件 | 记录 |
| --- | --- | --- |
| 外语/混语 | 正文含拉丁或其他非汉字字母（含大写缩写）；数字保留 | `foreign_transcript` |
| 热词全文回声 | 规范化全文 = 该路整表热词/明确整表序列化；禁止子串/单词误杀 | `hotword_echo` |
| 提示词全文回声 | 规范化全文 = 该模型该路实际 prompt/context/指令正文 | `prompt_echo` |

- 排除 ≠ 成功空转写 ≠ 无语音 ≠ 噪声。
- 全路排除 → `excluded`；部分排除 + 其余失败 → `manual_annotation`。
- 真实空输出（标签/标点独占）仍按空处理，不算上述三种排除。

---

## 6. 类别细则

### 6.1 voicemail

任意**未排除**路次命中 `voicemail_patterns_v1.yaml` 即入类并结束。无多族/稳定性/听音门槛。不进其他四类及其标注队列。

### 6.2 gold_candidate

须同时满足：

1. ≥3 独立合格稳定家族有有效中文代表；
2. 代表两两等价（仅明确无害差异；禁止链式合并）；
3. 否定、动作、对象、时间、数字、实体、陈述/疑问一致；
4. 其他有效中文路无实质反对、族内肯否冲突、真实空/有字冲突；
5. 无未决语义/声学疑点。

允许：同指「你/您」。不允许：「需要吗/需要啊」「需要/不需要」。全族一致「不需要」可入。

选文（资格通过后）：Qwen 权重 2，其他每族 1；同族双跑不加权。固定 `seed + sample_id + 策略版本` 可复现抽样。未逐条听音不得写 `is_human_verified=true`。

### 6.3 semantic_risk（仅三子类）

| 优先级 | 子类 | 要点 |
| --- | --- | --- |
| ② | `hallucinated_assertion` | 稳定空族 vs 稳定肯否族 + 音频/人工确认无目标语音支持；排除路不得当空族；漏识别短应答不入 |
| ③ | `short_polarity_ambiguity` | 所有有效代表最大汉字数≤4 + 应答模板 + 跨族肯否/空冲突 + 关键否定音节不可辨 |
| ① | `semantic_reversal` | 跨族同命题稳定正反；对象不同或「不知道/好的」等不入 |

旧宽标签（false_affirmation 等）不能直接定主类。证据不足 → 人工任务，不阻塞等待。

### 6.4 hardcase

≥2 未排除独立家族实质分歧（主内容/动作/对象/实体或大量非无害编辑），且未入严格风险、未确认环境噪声。须保留可审计分歧片段。家族不足、微量未解释字符差、全空 → 直接人工，不滥入 hardcase。

### 6.5 environment_noise

校准声学或人工听音确认以背景/串音为主、无可可靠转写目标语音。低 DNSMOS、全空、VAD 未检出、外语排除均不能单独入类。若满足幻觉②，主类归 `semantic_risk`。

---

## 7. 家族与选文

- 一家族一票；双跑只验稳定性。
- 配置双跑的家族仅剩一路：不能当已验证稳定支持票；若有实质反对内容仍不可忽略。
- 风险/共识必须基于跨族证据对，禁止全路字符串混判。

---

## 8. 人工任务

| 场景 | 任务类型 |
| --- | --- |
| 字符小分歧 / 家族不足 | `transcribe` |
| 疑似肯否风险 | `resolve_semantics` |
| 全空 / 空有字冲突 / 疑似串音 | `verify_target_speech` |
| 音频损坏或不可辨 | 允许 `invalid_audio` / `unintelligible` |

同一样本多问题合并为一任务；导入幂等，不覆盖已有人标。

---

## 9. 噪声诊断

- 落点：工序一③，ASR attach 之后；清洗不跑 DNSMOS。
- 主路径：分拣 YAML 内嵌 `quality.asr_anomaly_noise`（`diagnose_asr_anomaly`）；配置 `configs/quality/dnsmos_p835.yaml`，默认 `calibrated: false`。
- 研究旁路：`pipelines/audio_quality_sidecar.yaml` 全量评分；分拣失败不得自动改跑全量。
- 外语已排除，不得再因外语触发评分。
- 仅对真实空/有字冲突、短应答肯否冲突、显式非语音、可信串音信号及全族无有效转写等按需诊断。
- 评分失败/未校准 ≠ 噪声；直接送标（常为 `verify_target_speech`），不进等待池。
- `environment_noise` 仅在校准声学或人工听音确认后入类；低 DNSMOS / 全空 / VAD 未检出不能单独决定。
- 操作手册：`手册/*/01` §3b、`手册/*/00` §5b、`单条流水线执行命令.txt` §2f-noise。

---

## 10. 不变式

1. 排除路次不参与分类、信箱、噪声、空票、风险、选文。
2. 全路排除零人工任务；部分排除+失败 ≠ 全路排除。
3. 信箱任一路命中即结束。
4. 只输出五种业务类别；严格风险仅三子类。
5. 无待处理出口；人工任务必须可执行可回填。
6. ≥3 合格稳定族才可金标；反对证据不可忽略。
7. 不改原始转写、不覆盖人标、不把未校准噪声分当事实。
