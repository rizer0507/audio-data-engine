### 0A.1 改动摘要

| 项 | 实现 |
|----|------|
| 通俗解释落盘 | 逐条按真实规则改写全部 tag / 已登记流水线的 `description`；tag 写清都满足/满足其一；流水线写清做什么与得到什么 |
| 详情弹窗 | 只显示名称、解释、最近修改时间；按钮为编辑/关闭；编辑态仅一个解释文本框 + 保存/取消 |
| 保存字段 | 复用 `PATCH .../definition`，draft 仅允许 `description`；后端写 `description_updated_at`（UTC）；文字未变不刷新时间；打开/取消/归档不改时间 |
| 并发与范围 | 仍用 `expected_revision` + `definition_digest`；不改规则、业务版本、归档状态；不触发推理 |
| 无时间记录 | 前端显示「最近修改：尚未记录」 |

## 0. 增量修正（05 末尾提示词，2026-10-19）

按最新 `docs/web-service.md` 与 00～04，在**现有实现上增量修改**，未重建骨架。

### 0.1 改动摘要

| 项 | 实现 |
|----|------|
| source_id 自动生成 | `POST /sources` 只收 batch/路径等业务字段；分配 `src_<8hex>`；按 batch+规范化路径去重复用；PATCH 不换 ID |
| connection_id 自动生成 | `POST /models` 不收 connection_id；分配 `conn_<8hex>`；按 provider+base_url+model 去重；缺省显示名 `provider host:port` |
| batch → 引擎 source_name | 规划时解析登记表，写入冻结 `input.batch`/`input.path`；适配器优先用 batch，不用内部 ID 顶替 |
| 旧数据兼容 | 历史手写 source_id/connection_id 保留；缺 batch 时仅当 source_name 或 source_id 符合 `validate_source_name` 才当作 batch |
| 启用/归档 | `PATCH /api/v1/plugins/{kind}/{id}/status`；pipeline 写 `plugins.yaml`，tag 写定义 YAML；revision=目录 generation；幂等；刷新目录 |
| 归档拦截 | validate/plan 拒绝非 enabled；submit/rerun 额外检查 `PLUGIN_ARCHIVED` / 目录漂移 |
| 前端 | Sources/Models 去掉必填 ID；Jobs 按 batch/路径与模型名选择；Plugins 列表/详情有启用/归档与在用/归档筛选 |
