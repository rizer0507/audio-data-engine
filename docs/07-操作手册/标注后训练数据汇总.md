# 标注后训练数据汇总（036）

从**多个 batch** 的分类/标注 parquet（优先 `*_with_gold.parquet`）按配方抽取指定类别，清洗 `semantic_risk` 中「不做训练 / 不作训练语音信箱」等标记为 `hardcase`，写出**固定版本**训练 Manifest。

脚本：[`scripts/assemble_training_parquet.py`](../../scripts/assemble_training_parquet.py)  
清洗规则：[`configs/selection/training_exclude_markers_v1.yaml`](../../configs/selection/training_exclude_markers_v1.yaml)  
示例配方：[`configs/trainsets/zh_asr_mix_example_v001.yaml`](../../configs/trainsets/zh_asr_mix_example_v001.yaml)  
台账：[单条流水线执行命令.txt](../../单条流水线执行命令.txt) §2f-v3-036 · [手册/dev/05](../../手册/dev/05-一条命令多步骤.txt) §4  
需求：[036](../04-改进需求/进行中/036-标注-训练数据汇总.md)

> **自动 voicemail 不是金标。** 分类器对 ASR 文本命中 voicemail 正则只是自动隔离桶；本入口只清洗人工标注侧的「不做训练*」标记，**不改**分类器正则。详见 036 §4。

与 [032](../04-改进需求/进行中/032-工序一标注到Qwen3-ASR训练数据流水线设计.md) 关系：本入口是轻量「多 batch 指定类别 + 清洗 + 版本冻结」；032 的泄漏分组 / 配额 / Qwen JSONL / 训练启动**本期不做**。

## 1. 最短命令

在服务器项目根（与分类同一 conda）：

```bash
# 1) 复制示例配方，改 trainset_version / batches 路径
cp configs/trainsets/zh_asr_mix_example_v001.yaml \
   configs/trainsets/zh_asr_mix_20260921_v001.yaml
# 编辑该 YAML 后：

python scripts/assemble_training_parquet.py \
  --recipe configs/trainsets/zh_asr_mix_20260921_v001.yaml
```

或不用配方、显式参数：

```bash
python scripts/assemble_training_parquet.py \
  --version zh_asr_mix_20260921_v001 \
  --batch BATCH_A --batch BATCH_B \
  --categories gold_candidate,semantic_risk,hardcase \
  --rule-stem classified_five_class_v2_3_min_acoustic
```

---

## 2. 输入 / 输出

| 项 | 约定 |
|----|------|
| 默认输入 | `datasets/stage1/derived/classified_five_class_v2_3_min_acoustic_${BATCH}_with_gold.parquet` |
| 类别字段 | `reviewed_category` → `labels.category` → `type` |
| 清洗 | 仅对清洗前类别 ∈ `semantic_risk` 的 `gold_text` 匹配标记表 → `hardcase`；原文本进 `gold_text_raw`，`gold_text` 置空 |
| 过滤顺序 | **先洗再滤**：洗成 hardcase 后，若配方不含 `hardcase` 则丢弃（记 `dropped_after_clean`） |
| 版本目录 | `datasets/stage1/trainsets/<trainset_version>/`；同名默认不覆盖（需 `--overwrite`） |

产物：

```text
manifest.parquet   # 入选样本真相源
recipe.yaml        # 配方快照 + 输入 SHA256
summary.json/.md   # 完整统计与明细总览
lineage.json       # 样本 → 来源 batch / 清洗前后类别
details.csv        # 全量抽样明细（含未入选行）
```

---

## 3. 常用选项

| 选项 | 含义 |
|------|------|
| `--recipe PATH` | 配方 YAML（推荐） |
| `--version NAME` | 业务版本号（勿用时间戳冒充） |
| `--batch` / `--parquet` | 显式批次；parquet 可与 batch 一一对应覆盖默认路径 |
| `--categories` | 逗号分隔；**必须显式**，禁止默认吞全部五类 |
| `--duplicate-audio-policy` | `fail`（默认）/ `keep_first`：跨 batch 同 `original_audio_sha256` |
| `--exclude-markers-config` | 标记表路径 |
| `--overwrite` | 允许覆盖已存在版本目录 |
