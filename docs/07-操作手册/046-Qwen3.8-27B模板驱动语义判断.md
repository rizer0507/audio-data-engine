# 046｜Qwen3.8-27B 模板驱动语义判断

生产入口：`pipelines/semantic_judge.yaml`（算子 `semantic.judge`）。

## 1. 做什么

从**已含多家族 ASR 识别结果**的 Parquet 按任务配置抽取证据，渲染 Jinja system/user 模板，调用已启动的 vLLM **纯文本** Chat（`/v1/chat/completions`），Schema 校验后写入新 Parquet：

`labels.semantic_results[<task_id>]`

判断目标与用哪些家族/路次，只由任务 YAML + `.jinja` + JSON Schema 决定；换业务不改 Python。

## 2. 环境与服务

| 变量 | 含义 |
|------|------|
| `SEMANTIC_JUDGE_API_BASE` | OpenAI 兼容基址（覆盖服务 YAML） |
| `SEMANTIC_JUDGE_API_KEY` | API Key（默认 env 名，可在服务 YAML 改 `api_key_env`） |
| `SEMANTIC_JUDGE_MODEL` | served-model-name |
| `SEMANTIC_JUDGE_MODEL_REVISION` | 权重/缓存身份；换权重必须改 |

服务配置：`configs/semantic/services/qwen38_27b.yaml`  
HF 模型标识：`Qwen/Qwen3.8-27B`；请求里的 `model` 必须等于 vLLM `--served-model-name`。

示例启动（版本与参数以实测为准，写入本机部署记录）：

```bash
vllm serve Qwen/Qwen3.8-27B --served-model-name Qwen3.8-27B
```

首版不负责自动拉模型/分配 GPU/启停服务。结构化输出默认 `response_format.json_schema`；若部署不支持，须在服务 YAML **显式**改为 `prompt_schema_validate`（禁止静默降级）。

## 3. 任务切换

| 任务 | 配置 |
|------|------|
| 跨家族语义冲突 | `configs/semantic/tasks/semantic_conflict_v1.yaml` |
| 指定家族意图 | `configs/semantic/tasks/intent_v1.yaml` |

改流水线步骤里的 `params.task_config` 即可。多任务可多 step 或分次跑；结果按 `task_id` 共存，互不覆盖。

## 4. 命令

生产（占位符自行替换）：

```bash
audio-data pipeline run pipelines/semantic_judge.yaml \
  --input-manifest <已有多家族结果.parquet> \
  --output-manifest datasets/stage1/derived/semantic_conflict_<batch>.parquet
```

续跑：

```bash
audio-data pipeline run pipelines/semantic_judge.yaml --resume <runs/...目录>
```

Mock（无真实服务）：

```bash
audio-data pipeline run pipelines/semantic_judge.yaml \
  --input-manifest <小样本.parquet> \
  --output-manifest datasets/stage1/derived/semantic_mock_<batch>.parquet \
  --mock
```

意图任务示例：复制 YAML 或临时改 `task_config` 为 `configs/semantic/tasks/intent_v1.yaml`。

## 5. 并发预算

`parallel_shards * workers` 不得超过服务配置 `max_concurrency_total`。CLI `--workers` 覆盖也会预检；超预算直接报错。重试占用同一请求门闩，不另开无界池。多个独立 `pipeline run` **不共享**该预算，需自行给同一服务拆容量。

## 6. 缓存与恢复

- 缓存身份含：样本身份与白名单上下文、家族/路次文本与状态、task/模板/依赖/Schema、模型名与 revision、生成参数、mock 标志。
- 不靠音频 SHA 或通用 `completed` 跳过其它任务。
- `--resume` 复用同指纹成功/跳过结果，补跑失败与未完成行；Mock 结果不会在真实模式复用。
