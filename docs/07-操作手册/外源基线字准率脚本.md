我现在可能通过一个外源的标注文件A作为计算字准率的baseline，我想写一个脚本，传入不同模型的识别结果的parquet或者是jsonl,
- 首要的是将A的文件的id与对应的baseline提取出来，一般我会以wav文件的路径中的文件名去掉后缀作为文件名，A中的id一定至少包含这个文件名。
- 在对齐id之后根据baseline计算不同模型对这个baseline的字准率，计算字准率的过程参考当前的计算字准率流水线

---

已落地脚本：`scripts/eval_external_baseline_cer.py`（**只算 CER、不分 type**）

```bash
python scripts/eval_external_baseline_cer.py \
  --baseline 数据集/标注A.xlsx \
  --baseline-text-col label_text_raw \
  --model qwen=datasets/manifests/qwen_asr_mt3000.parquet \
  --model sensevoice=datasets/manifests/sensevoice_asr_mt3000.parquet \
  --output datasets/exports/external_baseline_cer_mt3000.parquet

# 或对聚合结果一次算多个模型
python scripts/eval_external_baseline_cer.py \
  --baseline 数据集/标注A.xlsx \
  --manifest datasets/manifests/multi_asr_aggregate_mt3000.parquet \
  --models qwen,sensevoice \
  --output datasets/exports/external_baseline_cer_mt3000.xlsx
```

对齐：精确匹配 → `A.id` 包含模型 id/stem。指标：`zh_asr_v1` + MetricRunner CER（evaluation）。

## 需要分 type + 正式评测时（推荐）

```bash
audio-data pipeline run pipelines/classify_external_gold.yaml \
  --source-name "$BATCH" \
  --aggregate-base qwen3-asr \
  --external-gold 数据集/标注A.xlsx \
  --label-col label_text_raw \
  --force

audio-data eval register "datasets/manifests/classified_${BATCH}.parquet" \
  --name "eval_${BATCH}"
```
