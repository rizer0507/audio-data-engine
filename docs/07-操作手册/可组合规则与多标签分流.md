## 2. Tag 定义库（042）与新增规则

| 路径 | 作用 |
|------|------|
| `configs/tagging/library/<tag_id>.yaml` | **一 tag 一文件**：业务含义、版本、状态、依赖、正反例、完整 `rules[]` |
| `configs/tagging/fragments_v1.yaml` | 公共条件片段（不自动代表 tag） |
| `configs/tagging/lexicons/` | 词表／正则（匹配数据） |
| `configs/tagging/zh_asr_multi_tag_v1.yaml` | 运行配置：`library` + **显式** `select_tags` + 证据／声学参数 |

新增 tag（通常无需改 Python／复制流水线）：

1. 复制 `configs/tagging/library/_example_new_tag.yaml` → `library/<新tag_id>.yaml`（去掉 `_` 前缀）
2. 写清 `tag_id`／`version`／`status`／`business_definition`／`examples`／`rules`
3. 在运行配置 `select_tags` 中显式加入 `{tag_id, version}`（**未选入不会自动打标**）
4. `audio-data tags validate -c configs/tagging/zh_asr_multi_tag_v1.yaml`
5. `audio-data tags docs --generate` 更新可读总览

路径解析（不依赖偶然 CWD）：相对路径依次尝试「运行配置所在目录 → 仓库根 → 当前工作目录」。库文件、片段、词表均走同一规则。

仍兼容旧内联 `tags:` / `rules:` 配置；与库选中同一 ID 时拒绝覆盖。

### 2.1 043：`semantic_risk_text_disagreement`

默认运行配置已显式选入该 tag（版本 `"3"`），库文件：`configs/tagging/library/semantic_risk_text_disagreement.yaml`。

两个分支均执行 Qwen 排除词表 `configs/tagging/lexicons/semantic_risk_qwen_exclusions.yaml`：对去控制标签、标点和空白后的 Qwen 稳定代表文本做包含匹配，命中“不需要、不用、不要、不可用、没有”任一项就不检出本 tag；“沒有”同样排除。“不需要了，谢谢”等含后缀文本也排除。此条件只检查 Qwen，SV/GLM 的否定词不触发排除，也不改变其他 tag。

| 规则 | 含义 |
|------|------|
| `rule_semantic_risk_keyword_sg_qwen_v1`（规则版本 2） | 分支 A：全族双跑成功 + 三族 stable_text + Qwen 未命中排除词；任一六路原文命中 `semantic_risk_keywords`；SV≈GLM 且 Qwen≉SV（不限长度） |
| `rule_semantic_risk_single_char_pairwise_v1`（规则版本 5） | 分支 B：同上前置；Qwen 代表文本为 1~3 个汉字，SV/GLM 不限长度；三族两两不等价（不要求准入关键词，但适用 Qwen 排除词表） |

业务组合为 **Qwen 未命中排除词且 ((A) 或 (B))**；任一分支命中即添加同一 tag，逐规则保留三态与证据。两分支可以同时命中，有效 tag 去重且保留两条规则来源。两条 `rule_id` 保留旧名称以兼容历史引用，新条件由各自规则版本标识。维护时：

- 改组合条件 → 只改库文件，并提升 tag/rule 版本，同步 `select_tags`
- 改关键词 → 只改 `configs/tagging/lexicons/semantic_risk_keywords_1012.yaml`（或注册的新词表文件）并提升词表版本
- 改 Qwen 排除词 → 修改 `configs/tagging/lexicons/semantic_risk_qwen_exclusions.yaml` 并提升排除词表版本；不要删除准入词表中 GLM/SV 可用于证明语义分歧的否定词
- 旧内联对照配置 `configs/tagging/semantic_keywords_sg_qwen_1012.yaml` 与旧 `tag_1` **保留原 ID/含义**，不要借旧 ID 扩义

```bash
audio-data tags show semantic_risk_text_disagreement
audio-data tags explain --batch "$BATCH" --sample-id <id> --rule-id rule_semantic_risk_keyword_sg_qwen_v1
audio-data tags explain --batch "$BATCH" --sample-id <id> --rule-id rule_semantic_risk_single_char_pairwise_v1
```

### 2.2 疑似含糊人声：`qwen_unclear_speech_candidate`

用于挖掘可能说话含糊的候选，仍需人工听音确认。三个条件同时满足：DNSMOS SIG 低档
（evidence `dnsmos_weak_sig=2.8`，capability `dnsmos_sig_low`，比较为 SIG<=阈值）；
Qwen 至少一次成功产生清洗前原始非空转写；SenseVoice/GLM/Qwen 的成功结果存在跨模型分歧。
允许家族双跑不稳定或部分路次失败；三家各需至少一条可比较的成功结果，任意跨家族成功路次
按现行无害等价不一致即成立。成功空输出也参与比较，失败、缺失和排除路次不充当空输出。

本 tag **不依赖 Silero VAD**。默认 `evidence_mode=existing` 时缺 DNSMOS 为 unknown；
`compute_acoustic` 下文本条件可成立时仅补算 DNSMOS，不触发 VAD。SIG 低档不能直接证明吐字含糊，
仍需人工听音。

```bash
audio-data tags show qwen_unclear_speech_candidate

# 正式跑批（缺 DNSMOS 时补算）
audio-data tags run --batch "$BATCH" \
  -c configs/tagging/zh_asr_free_tags_v2.yaml \
  --evidence-mode compute_acoustic \
  --rule-id rule_qwen_unclear_speech_candidate_v1

# 导出候选；可按已有成功 SIG 升序排列。
audio-data tags export \
  -c configs/tagging/zh_asr_free_tags_v2.yaml \
  --input datasets/stage1/derived/tagged_free_tags_v2_$BATCH.parquet \
  --output data/exports/unclear_speech_candidates_$BATCH.parquet \
  --include-all qwen_unclear_speech_candidate \
  --sort-by-dnsmos-sig
```

打标摘要 XLSX 的 `samples` 页同时提供 `dnsmos_status`、`dnsmos_sig` 参考列，便于筛选 tag 后排序和抽听。
三模型分歧也可能来自方言、短句等因素，不自动等于发音含糊。

## 4. 样本字段、快照与有效标签

- `labels.tags`：去重后的有效 tag_id 列表
- `labels.tagging`：`policy_version` / `snapshot_id` / `eval_status`（tagged|untagged|unresolved|not_evaluated）/ 规则覆盖率
- 有效标签 =（自动命中 ∪ 人工添加）− 人工屏蔽；多来源同 tag 只显示一次
- 每次运行写入完整 `definition_snapshot.json`（所选 tag／规则／递归片段／词表全文与匹配参数／声学配置 + `content_fingerprint`），并随 published 快照绑定；**不只保存路径摘要**

## 5. 与旧五类 / 训练门禁 / 041 切段

- 不覆盖旧 `category` / `risk_tag` / `noise_kind`
- 仅有 tag ≠ 人工金标 / 训练准入；训练抽取仍走现有完成门禁与排除契约
- 041 切段：库中规则对每个保留片段独立判断；片段 `id`／父源血缘字段由上游样本携带，打标不丢弃；tag 定义库与样本上的打标结果分别管理

## 6. 环境限制

- **真实 Silero VAD / DNSMOS 推理**：本机交付以模拟适配器验证调度（零调用、共享去重、失败隔离）。服务器模型可用后再做真实声学 smoke，勿把模拟成功写成真实推理成功。
- 默认 `evidence_mode=existing`：缺声学证据的规则为 `unknown`，不伪造。
