# 改进需求

本目录存放**准备发生或曾经发生**的修改，不是项目当前事实。

- **进行中/**：尚未完全落地的设计与实施说明；**不能默认认为已经实现**
- **已完成/**：历史开发资料；落地后的现行说明应已写入 `01-项目架构/`、`02-规范规则/`、`03-流水线/`

## 如何提交新需求

当前五类自动分类修复需求：[028-五分类自动噪声归类与互斥准入修复](./进行中/028-五分类自动噪声归类与互斥准入修复.md)，文末附 Cursor 执行提示词；与 027 冲突时以 028 为准。

1. 复制 [需求文档模板.md](./需求文档模板.md)，用自然语言写清想法
2. 放入 `进行中/`，建议编号：`00N-简短中文名.md`
3. 交给 AI 时附带：[流水线构建-AI执行手册](../07-操作手册/流水线构建-AI执行手册.md)

编号只表示收录顺序，不表达优先级。
