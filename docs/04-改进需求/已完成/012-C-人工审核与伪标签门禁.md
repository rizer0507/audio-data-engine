## 1. 目标与硬约束（母文档 §1，全局适用）

交付可复现链路：

```text
数据源快照 + 音频分组/查重 + 八路 ASR
  → DNSMOS 独立评分
  → 四家族状态与业务风险分析
  → 候选分类 + Qwen 纠错价值 + 人审队列
  → 人工听审 / 双审 / 仲裁 / 伪标签抽检
  → train / dev / eval_core / eval_random 独立冻结
  → Qwen Base / LoRA / Full SFT 在相同评测集上的 CER + 业务风险指标
```

必须满足：

1. 同家族两次推理用于发现不稳定性，最多计一票；四家族也可能共同出错，共识不等于真实标签。
2. Qwen 不担任金标基准，不享有投票加权；Kimi、GLM、SenseVoice 是三个辅助家族，不预设某一个绝对正确。
3. 任何一路出现业务语义冲突都须保留，禁止用族内 medoid 或多数票掩盖。
4. 正式评测仅用经验证的人工/外源金标；伪标签只允许进入通过抽检门禁的训练子集。
5. 输入已是上游切分段，不新增、不调用、不依赖 VAD；不生产 `speech_ratio` / `vad_edge_risk`。
6. DNSMOS 只衡量音频质量，不能判定无人声、串音、说话人归属或语义正确性。
7. 原始音频与八路原文只读；禁止自动拼接多个转写创造标签，禁止将“不”“嗯”等关键内容清空。
8. 所有阈值、词表、配额、审核规则版本化；校准未通过时允许分拣和送审，禁止自动发布伪标签训练集。

## 3. 人工标注契约（母文档 §7 全文）

### 3.1 必填字段

```text
sample_id / original_audio_sha256 / queue_id / queue_revision
annotation_state = pending | annotated | second_review | conflict | adjudicated | rejected
gold_kind = speech | non_speech | unintelligible | ambiguous_target | invalid
gold_text = null | "" | 非空文本
speech_scope = target | background_only | mixed | none | unknown
human_semantic = positive | negative | neutral | mixed | unknown | not_applicable
human_noise = clean | moderate | noisy | unknown
human_crosstalk = true | false | unknown
verified_error_tags[]
annotator_id / reviewer_id / adjudicator_id / timestamps / annotation_revision
```

- `null` 表示未完成/无法确认；`""` 只表示人工确认的非语音空真值，两者不可互换。
- speech 要求非空逐字转写；保留“嗯、啊、不、没”、口吃和实际拒绝，不润色、不补全、不根据业务意愿改词。
- non_speech 要求 `gold_text=""`、明确音频事件标签（静音/环境声/音乐/忙音等）及人工确认；不填“噪声”作为识别目标文本。
- 听到人声但听不清，标 unintelligible，不标空；能听到多个说话人但无法确定目标，标 ambiguous_target，不猜金标。
- 标注协议固定目标：优先按来源提供的客户声道/角色标记；缺少角色证据且多人声时不得凭文本推断客户。背景人声不能作为 non_speech；是否训练为空取决于另行明确的目标说话人抑制任务，首版隔离。
- 混合语音仍可可靠确认目标且完整转写时，允许 speech + human_crosstalk=true。局部不可辨认片段首版不导出完整句训练标签。
- 可信外源按同一字段契约导入，记录供应方、标注协议、版本和验收记录；普通 xlsx 上传不自动授予 trusted_external。

### 3.2 听审流程

1. 一审先听未 pad 原音频，填写独立转写与标签，再显示匿名、随机顺序的候选供核对；顺序种子可追溯。
2. 正式 eval 全量、P0、所有拟采用空金标及高置信伪标签抽检样本必须由不同标注员独立双审；二审看不到一审答案或家族名。
3. 两审在关键词、转写、gold_kind、目标说话人或极性上不同，进入第三人仲裁；无法裁定则 rejected/隔离。
4. 其他训练人审样本单审后按来源与风险分层复核至少 10%；发现关键错误则扩大该层复核。
5. 只有通过规定审核级别的样本写 `label_tier=gold`、`label_source=human`、`is_human_verified=true`；不允许操作员用一个 accepted 绕过二审。
6. 导入校验队列、样本、哈希、标注员与 revision；拒绝未知/重复 ID、旧版覆盖、不可编辑列改动。部分导入只推进已完成样本，其余保持 pending。
7. 每次导入写新 annotation artifact，不改原八路转写、不覆盖历史分类；人工标签升级不触发重新分配 eval 到 train。

首版用独立 XLSX/JSONL 审核包与已有人工工具完成，不要求开发完整标注 Web 平台。盲审包不包含可直接看到的模型答案；需要候选核对时提供独立的后续视图。

## 4. 审核预算与伪标签放行（母文档 §8 全文）

- P0 全部进入待审队列；标注预算不足时按优先级选批，未审部分留池，不因积压放宽自动准入。
- P1 内优先：Qwen 存在肯定幻觉候选、teacher 一致/Qwen 错、短否定句、全空、噪声与串音。
- P2 按来源、时长、质量、家族状态分层选取；每层使用稳定种子和组内去冗余，不能只挑最长或最容易的文本。
- 首轮校准池目标 3000 条，可配置 2000～5000，来源只能是开发池；用途 `calibration`，不进入正式评测。词表、DNSMOS 阈值、相似度阈值只在该池调节。
- 规则冻结后从拟自动接受的训练候选中另抽独立审计样本：每个生产批次均匀随机抽至少 500 个不同泄漏组，每组随机一条；该统计明确命名为“组均衡误标率”，不冒充按音频条数加权的总体错误率。不得用调阈值的校准样本自证质量。
- 初始自动发布门禁：总体组均衡文本错误率 Wilson 95% 区间上界 ≤1%；关键语义错误观测数必须为 0；短句、否定、肯定、moderate 质量等受保护层各随机抽至少 200 个独立组、每组一条，层内上界 ≤2%。文本错误指 comparison_text 与人工转写不一致，关键语义错误另计。
- Wilson 使用双侧 95% 区间的上端点（z=1.96）。各层分别报告 n、错误数、区间、种子；重叠审核记录可复用，但不得将加抽层直接混入总体样本计算错误率。不足样本数的层全量人工确认或保持不放行；如需联合置信结论另配置多重比较校正，不宣称这些单独区间具有联合 95% 置信度。
- 发现关键语义误标立即停止相关层伪标签发布，回查规则，生成新版本后重新独立抽检。禁止回写修改已冻结 Release。
- 每次新增来源、改变八路模型/提示词/预处理、修改规则或噪声阈值，重新获得对应范围的审计证据。抽检门禁是工程验收标准，不代表总体绝对无误。

## 6. 验收用例：标注与数据安全（母文档 §15.2 全文）

- accepted non_speech 空字符串可完整经过审核、Release、支持空目标的训练导出及 eval；pending/null 和 unintelligible 不得通过。
- 一审填完不等于双审完成；同标注员自审、冲突未仲裁、旧 revision 导入均被拒绝。
- 人工导入保留原 type/risk_tags/八路原文；人审 gold 与 candidate_text 独立。
- 不同路径相同音频、同通话、同源切片、增强、已确认近重复跨集合均阻断发布。→ **与 A/D 协同**
- eval 保留但未入选的同组样本也不得进入训练；缺 group 元数据不能静默退回按 ID 随机拆分。→ **与 A/D 协同**
- 随机集名单不因 ASR、DNSMOS、分类或新模型结果变化；所有排除可追溯。→ **与 A/D 协同**
- 输出配额不足、审计失败、标注未完成时不得宣称生成正式 Release。→ **与 D 协同；本阶段保证审计失败/标注未完成可阻断**
- 同输入、配置、版本、seed 在不同顺序/分片/续跑下得到相同分类、采样 ID 与内容摘要。→ **与 A/B/D 协同**
- 重复发布幂等；同 ID 不同内容先失败，不覆盖既有文件。→ **D**

本阶段必须通过的验收重点：

- 空金标 `""` 与 `null` 不可互换；pending/null、unintelligible 不得通过正式路径。
- 盲审、双审、仲裁、revision 校验全部生效；不允许单 accepted 绕过二审。
- 伪标签独立抽检门禁（组均衡误标率、Wilson 上界、关键语义错误为 0、受保护层）全部可计算、可阻断。
- 校准池与独立审计样本分离；不得用校准样本自证质量。
- 发现关键语义误标立即停止相关层伪标签发布；禁止回写修改已冻结 Release。
