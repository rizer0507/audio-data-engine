拿到某个 source 的**外源金标 xlsx** 后：同 family 推理 → 复用清洗/分拣 → 产出正式 `classified_*`（金标以外源为准）→ 直接喂工序三。

### 正式主路径

```bash
audio-data pipeline run pipelines/data_cleaning_source_A.yaml \
  --source-name "$BATCH" --source-dir "$SOURCE_DIR"
audio-data pipeline run pipelines/qwen_asr_batch.yaml \
  --source-name "$BATCH" --asr-run qwen3-asr

audio-data pipeline run pipelines/classify_external_gold.yaml \
  --source-name "$BATCH" \
  --aggregate-base qwen3-asr \
  --external-gold path/to/外源金标.xlsx \
  --label-col label_text_raw \
  --force

audio-data eval register "datasets/manifests/classified_${BATCH}.parquet" \
  --name "eval_${BATCH}"
# 其后同场景 1：跑批 → eval_aggregate → eval_metric_pipeline
```

### 外源分桶（external_gold_v1）

| type | 条件 |
| --- | --- |
| `voicemail` | 命中语音信箱正则 |
| `noise` | 双方皆空 → gold 占位 `噪声` |
| `auto_gold` | 清洗后与 compare_model 完全一致 |
| `hardcase` | 其余 |

### xlsx 要求

- 必有 id 列（`id`/`sample_id`…）与金标列（默认 `label_text_raw`）
- id 与 ASR parquet 一致、表内不重复
- 可用 `--id-col` / `--label-col` 覆盖
