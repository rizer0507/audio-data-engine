## 1. 我想做什么

把「工序一后置统一分类」这条**一条命令多步骤**入口，从现行：

```text
audio_energy → dnsmos_v2_2_candidates → classify(v2.2)
产物：*_five_class_v2_2_auto_noise_*
```

同步到与 034 一致的：

```text
audio_energy → silero_vad → efficientat_candidates → efficientat → classify(v2.3)
产物：*_five_class_v2_3_min_acoustic_*
DNSMOS：默认不跑；若保留仅为旁路 quality_tag，且 classify 不得消费
```

入口形态保持不变（脚本与 CLI 等价、前置体检、不占 ASR GPU），只换**引擎编排、规则版本、默认产物 stem、手册命令**。

## 2. 当前缺口（相对最新规则）


| 项           | 现状（031 / 手册 §2）                                          | v2.3 目标（034）                                                                                              |
| ----------- | -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 规则版本        | `selection_five_class_v2_2_auto_noise`                   | `selection_five_class_v2_3_min_acoustic`                                                                  |
| 侧车编排        | `audio_energy` + `dnsmos_v2_2_candidates`                | `audio_energy` + **全量** `silero_vad` + **候选** EfficientAT                                                 |
| 主声学证据       | DNSMOS 联合判定                                              | Silero speech + EfficientAT 事件；DNSMOS 废止为主依据                                                              |
| 默认 XLSX     | `summary_five_class_v2_2_auto_noise_${BATCH}.xlsx`       | `summary_five_class_v2_3_min_acoustic_${BATCH}.xlsx`（分片名可按 034）                                           |
| 默认 parquet  | `classified_five_class_v2_2_auto_noise_${BATCH}.parquet` | `classified_five_class_v2_3_min_acoustic_${BATCH}.parquet`                                                |
| 配置          | `zh_asr_five_class_v2_2_auto_noise*.yaml`                | `zh_asr_five_class_v2_3_min_acoustic*.yaml` + `silero_vad_v1` / `efficientat_v1` / `acoustic_evidence_v1` |
| 流水线等价       | `classify_dataset_five_class_v2_2_auto_noise.yaml`       | `classify_dataset_five_class_v2_3_min_acoustic.yaml`                                                      |
| `too_short` | v2.2 可能进噪声子类                                             | 仅 `quality_tag=short_audio`，继续进正常分类                                                                       |
| 明细列 / 统计页   | 偏 DNSMOS / `v2_fallback`                                 | 须含 VAD / `audio_event_state` / `acoustic_state` / `decision_evidence`；DNSMOS 回退统计降级或移除为主指标                |


**不变（031 已验收语义继续成立）：**

- `--batch` + 六路 ASR 前置体检（按家族/路次列缺失）；缺路非零退出。  
- 别名优先级：`--family` > dataset YAML > stage1 固定 `qwen_1/2` 等。  
- 不启动 ASR、不伪造正式身份。  
- 行数守恒、原子写入、默认不覆盖（须 `--overwrite`）。  
- 脚本与 `audio-data stage1 classify` **同一实现**，禁止第三套半兼容路径。

## 3. 同步更新方案



### 3.1 依赖门槛（开工前）

本需求实现前，下列 034 交付物须已可用（或本需求与 034 **同 PR / 同批次** 合入，但入口不得在引擎未就绪时静默回退到 v2.2）：

1. `pipelines/classify_dataset_five_class_v2_3_min_acoustic.yaml`
2. `configs/selection/zh_asr_five_class_v2_3_min_acoustic.yaml`
3. 算子：`quality.silero_vad`、`quality.efficientat_candidates`、`quality.efficientat`
4. 分类器：`selection_five_class_v2_3_min_acoustic` 已挂到 `quality.classify`
5. 质量配置：`configs/quality/silero_vad_v1.yaml`、`efficientat_v1.yaml`、`acoustic_evidence_v1.yaml`

若依赖未齐：入口应**明确失败**（提示跑 034 / 指定旧版本），禁止默默用 DNSMOS 冒充 v2.3。

### 3.2 默认策略版本切换


| 策略       | 约定                                                                                |
| -------- | --------------------------------------------------------------------------------- |
| **新默认**  | 后置入口默认 `v2_3_min_acoustic`（与 034 正式入口对齐）                                          |
| **兼容旧批** | 保留显式开关跑 v2.2，例如 `--rule-version v2_2_auto_noise` 或 `--legacy-v2-2`（实现二选一，文档只保留一种） |
| **禁止**   | 同一默认路径写出 v2.2 stem 却声称 v2.3；禁止覆盖已有 `*_v2_2_`* / `*_v2_3_*` 除非 `--overwrite`       |


推荐 CLI 形态（与现手册兼容，仅增版本与声学配置）：

```bash
# 默认：v2.3 最小声学（034）
python scripts/classify_asr_to_xlsx.py --batch "$BATCH" --energy-workers 32
# 等价：
# audio-data stage1 classify --batch "$BATCH" --energy-workers 32

# 显式指定（建议支持，便于对照与回滚）
# audio-data stage1 classify --batch "$BATCH" --rule-version v2_3_min_acoustic
# audio-data stage1 classify --batch "$BATCH" --rule-version v2_2_auto_noise   # 旧口径复现
```

`--energy-workers` / `--workers`：继续只加速 **audio_energy**（或后续文档写明是否扩展到 Silero 线程池）；EfficientAT 并发按 034 算子/配置，不与 energy-workers 混名误导。

### 3.3 入口内编排替换（实现要点）

在 `scripts/classify_asr_to_xlsx.py`（及 CLI 薄封装）中：

**默认路径（v2.3）：**

```text
aggregate / attach（与现逻辑一致）
→ quality.audio_energy
→ quality.silero_vad          # 全量
→ quality.efficientat_candidates
→ quality.efficientat         # 仅候选
→ quality.classify            # rule_version=selection_five_class_v2_3_min_acoustic
→ 落盘 classified parquet（可选关闭）
→ review export-summary 契约 → 完整 XLSX
```

**兼容路径（仅** `--rule-version v2_2_auto_noise`**）：**

```text
→ audio_energy → dnsmos_v2_2_candidates → classify(v2.2)
→ 产物 stem 仍用 v2_2_auto_noise（隔离）
```

实现偏好：

1. **优先**内部调用与 `pipelines/classify_dataset_five_class_v2_3_min_acoustic.yaml` 相同的算子序列与配置加载，避免入口与正式流水线漂移。
2. 若继续「脚本内手写算子链」，必须与 YAML 步骤一一对应，并在帮助文案写清「与 pipeline 语义等价」。
3. DNSMOS：v2.3 默认跳过；若加 `--with-dnsmos-tag`，仅写 quality_tag，**不得**进入类别决策。

## 4. 验收标准（我怎么才算满意）

- [ ] 一条命令（脚本或 `stage1 classify`）在六路 ASR 已齐时产出 **v2.3** 完整 XLSX +（默认）classified parquet，stem 含 `v2_3_min_acoustic`。

- [ ] 缺任一路 ASR 时，报错仍按家族/路次列出期望路径（031 行为不回退）。  
- [ ] 默认路径**不**调用 DNSMOS 作为分类依据；主决策字段可见 VAD / acoustic 证据。  
- [ ] `--rule-version v2_2_auto_noise`（或等价）仍可产出隔离的 v2.2 文件，且不覆盖 v2.3 默认路径。
