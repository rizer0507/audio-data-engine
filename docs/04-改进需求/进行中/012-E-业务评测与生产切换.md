## 1. 目标与硬约束（母文档 §1，全局适用）

交付可复现链路：

```text
数据源快照 + 音频分组/查重 + 八路 ASR
  → DNSMOS 独立评分
  → 四家族状态与业务风险分析
  → 候选分类 + Qwen 纠错价值 + 人审队列
  → 人工听审 / 双审 / 仲裁 / 伪标签抽检
  → train / dev / eval_core / eval_random 独立冻结
  → Qwen Base / LoRA / Full SFT 在相同评测集上的 CER + 业务风险指标
```

必须满足：

1. 同家族两次推理用于发现不稳定性，最多计一票；四家族也可能共同出错，共识不等于真实标签。
2. Qwen 不担任金标基准，不享有投票加权；Kimi、GLM、SenseVoice 是三个辅助家族，不预设某一个绝对正确。
3. 任何一路出现业务语义冲突都须保留，禁止用族内 medoid 或多数票掩盖。
4. 正式评测仅用经验证的人工/外源金标；伪标签只允许进入通过抽检门禁的训练子集。
5. 输入已是上游切分段，不新增、不调用、不依赖 VAD；不生产 `speech_ratio` / `vad_edge_risk`。
6. DNSMOS 只衡量音频质量，不能判定无人声、串音、说话人归属或语义正确性。
7. 原始音频与八路原文只读；禁止自动拼接多个转写创造标签，禁止将“不”“嗯”等关键内容清空。
8. 所有阈值、词表、配额、审核规则版本化；校准未通过时允许分拣和送审，禁止自动发布伪标签训练集。

## 3. 业务评测与回归门禁（母文档 §13 全文）

扩展统一 MetricRunner；每个指标必须输出 `numerator/denominator/value/eligible_count/excluded_count`，分母为 0 输出 null，禁止记为 0%。

以下为本项目 v1 指标定义，语义判定器须版本化并用人工标注校准：

- **CER**：仅 gold_kind=speech 的可评估样本，`sum(S+D+I)/sum(reference_length)`；同时报 S/D/I 率。non_speech 单独统计，不混入主 CER。
- **NFR**：人工明确 negative 样本中，输出被判 positive 的条数 / 人工明确 negative 样本数。
- **FAR**：人工明确无肯定的样本（negative、neutral、确认 non_speech）中，输出被判 positive 的条数 / 这些样本总数。mixed/unknown 不进分母。
- **NAHR**：人工 non_speech 且音频事件含环境噪声/忙音/音乐的样本中，输出被判 positive 的条数 / 此类样本数；纯静音单独报同口径切片。
- **FAER**：人工确认纯语气词/中性短反馈的样本中，输出被判 positive 的条数 / 此类样本数；不把“嗯，我不需要”当纯语气词。
- **NSHR**：全部人工 non_speech 中，输出任意非空文本的条数 / 人工 non_speech 样本数。
- **肯定保留率**：人工明确 positive 中输出仍为 positive 的条数 / 人工 positive 样本数，防止通过全部输出空/否定降低风险指标。
- **推理失败率**：失败或缺失预测数 / 应预测样本数；与真实 success_empty 分开。

输出 mixed/unknown 的预测不算已确认 positive，但单独报语义不可判率与“unknown 全算风险”的保守上界；正式提升结论须完成影响结论的模糊样本裁定或满足预设不可判门禁，禁止通过让判定器认不出文本降低风险率。

正式比较要求固定样本上预测齐全；任一模型 failed/missing 可以出诊断报告，但发布门禁为 incomplete，不按模型分别删样本或将失败填空。配对置信区间按 leakage_group 重采样，防止同一电话多片段虚增统计量。

报告分别展示 eval_core、eval_random，总体及否定/肯定/语气词/短句/噪声/串音/来源切片；Base 和每个微调权重使用相同解码设置。每个权重固定一个主评测运行，第二次仅报告稳定性，不能择优挑运行。

发布门禁配置包括：主业务指标、最小有意义改善量、CER/肯定保留率/NSHR 非劣容忍度、置信水平、最低分母、最大语义不可判率。初版不硬编码未经业务校准的增益阈值；缺配置或样本不足返回 needs_review，不自动 pass。仅主指标满足改善且保护指标未退化才可 pass。

## 5. 验收用例：指标与工程（母文档 §15.3 全文）

- CER、NFR、FAR、NAHR、FAER、NSHR、肯定保留率分别有可人工核算的分子分母测试；零分母 null、失败预测 incomplete。
- 全输出空不会通过肯定保留率；未知极性不能制造虚假的低风险通过。
- DNSMOS 以固定真实 WAV 验证原始分数与所固定官方实现一致（容差配置），覆盖短片段、采样率、失败隔离和缓存失效；不得用 mock 宣称模型评分验收通过。→ **B 主责，本阶段回归联调**
- 质量特征传到分拣后，noisy 开关确实改变自动接收决策；任何高相似度仍不能覆盖 P0。→ **B 主责，本阶段回归联调**
- 单元测试覆盖纯逻辑；离线集成验证八路聚合→分类→双审导入→冻结→多模型报告；最后在目标机器逐级 1k/10k/全量验证吞吐、内存、守恒与恢复，报告实际测得数据。
- 回归现有 v1/v2、独立 ASR 和外源金标路径。更新 docs 索引、工序总览、规则规范、执行手册及命令台账，注明 v3 生产切换门禁；未通过人工校准不得修改生产默认。

为不丢内容，母文档 §15.1 / §15.2 全文亦收录于此（主责已在 B/C/D，本阶段做端到端回归）：

### 5.1 判定正确性（母文档 §15.1）

- 四家族双跑均为“我不需要”：短句完全一致且质量/审计通过 → pseudo_high，仍不得正式 eval。
- 三个 teacher 都“我不需要”，Qwen 两路“我需要”：semantic_risk + qwen_correction_candidate，必须人审。
- Qwen 两路分别“需要/不需要”，其余六路一致“需要”：P0，不能丢弃 Qwen 负向输出后自动接受。
- 七路“需要”、一路“不需要”：P0，不按 7:1 自动收。
- 六路“嗯”、两路“需要”：filler_affirmation，P0。
- 一路“别再打电话”、其他输出肯定：拒绝美化风险，P0。
- 八路都成功空，无论 DNSMOS 高低：all_empty_unverified，必须人审。
- 七路空、一路“好的”：presence_conflict，P0；人工 non_speech 后才能作为空目标。
- 一路失败、七路空：inference_incomplete，不能当作八路空。
- 三 teacher 仅普通字词一致、Qwen 错字：无语义风险时 qwen_correction_candidate。
- 家族内部一空一非空：unstable_presence，不算稳定文本票。
- 2:2 或相似度传递链：不得自动伪标签。
- 四家族高一致但 DNSMOS noisy/unknown：送审，不自动收；八路一致也能被抽检发现共同错误。
- 双重否定、数字金额冲突、背景人声、语音信箱与语义风险同时命中均有独立测试。

### 5.2 标注与数据安全（母文档 §15.2）

- accepted non_speech 空字符串可完整经过审核、Release、支持空目标的训练导出及 eval；pending/null 和 unintelligible 不得通过。
- 一审填完不等于双审完成；同标注员自审、冲突未仲裁、旧 revision 导入均被拒绝。
- 人工导入保留原 type/risk_tags/八路原文；人审 gold 与 candidate_text 独立。
- 不同路径相同音频、同通话、同源切片、增强、已确认近重复跨集合均阻断发布。
- eval 保留但未入选的同组样本也不得进入训练；缺 group 元数据不能静默退回按 ID 随机拆分。
- 随机集名单不因 ASR、DNSMOS、分类或新模型结果变化；所有排除可追溯。
- 输出配额不足、审计失败、标注未完成时不得宣称生成正式 Release。
- 同输入、配置、版本、seed 在不同顺序/分片/续跑下得到相同分类、采样 ID 与内容摘要。
- 重复发布幂等；同 ID 不同内容先失败，不覆盖既有文件。
