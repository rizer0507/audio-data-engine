## 1. 我想做什么

在不推翻现行五分类业务骨架的前提下，用 **Silero VAD + EfficientAT（候选）** 替换 DNSMOS 在「是否有人声 / 是否环境噪声 / 是否人声噪声」上的主判定职责，修正 v2.2 声学证据目标错位。

职责拆分必须固定为：

```text
audio_energy  → 有没有物理声音
Silero VAD    → 有没有人类语音（speech evidence）
EfficientAT   → 主要是什么声音事件（仅候选样本）
ASR 家族四态  → 模型听成了什么、是否稳定一致
```

禁止继续使用以下错误等价：

```text
ASR disagreement ≈ noise
audible ≈ speech
DNSMOS noisy ≈ environment noise
DNSMOS SIG strong ≈ speech exists
```

改造性质：**最小改动增量**。复用 v2 / v2.2 的家族聚合、voicemail、semantic_risk、gold 选文、hardcase 兜底；新增声学侧车与分类器分支，不整套重写。

## 2. 当前问题与改造范围

### 2.1 当前问题（基于 029 / v2.2）

- DNSMOS 是感知质量分，不是 speech / noise 事件分类器；用它驱动 `environment_noise` 会把「听不清」和「不是人声」混在一起。
- `all_empty + audible`、短音频等规则会把真实短应答或 ASR 漏识别误判成噪声。
- 多家族同文 hallucination（多个 ASR 对非语音写出相同文本）缺少独立声学否决，可能误进 `gold_candidate`。

### 2.2 范围

**必须做：**

1. 接入 Silero VAD：对当前已切割 wav 做段内 speech 检测与占比统计（**不重新切割音频**）。
2. 接入 EfficientAT：仅对候选样本做 AudioSet 事件打分，并映射为 `audio_event_state`。
3. 聚合 `acoustic_state`，按决策矩阵改写五分类。
4. 新增规则版本、配置、流水线、产物命名隔离；更新执行命令台账。
5. DNSMOS 可旁路保留，**不得再作为主分类依据**。

**明确不做（本版本）：**

- WeSpeaker / CAM++ / pyannote / Brouhaha / diarization。
- 确认串音（`crosstalk`）自动类；不得把 babble 自动升级为「非目标客户」。
- 全量 EfficientAT（42 万级全量跑禁止作为默认）。
- 重构 voicemail 主逻辑。
- 覆盖 v1 / v2 / v2.2 历史产物、审核包、release、原始转写。

### 2.3 与旧规则关系

| 来源 | 关系 |
|------|------|
| 027 / 028 | 五类出口、家族四态、互斥、hardcase 兜底继续有效 |
| 029 | 作为直接基线；DNSMOS 联合判定在主决策中**废止**，可降级为 quality_tag |
| 033 | 规则与决策矩阵来源；本文把它落成可执行工程需求 |
| 上游「已做 VAD 切割」 | 继续成立：本流水线 **不重切段**；Silero 只回答「当前 wav 内有没有 speech」 |

Cursor 开工时应重新核查工作区代码，不把本文快照当永远准确的路径事实。

## 5. 文本证据（保持并显式化）

### 5.1 家族四态（不变）

| 状态 | 定义 |
|------|------|
| `stable_text` | 两路成功且文本一致 / 仅无害差异 |
| `stable_empty` | 两路成功且清洗后均为空 |
| `unstable` | 一空一有字、实质冲突、单路成功等 |
| `unavailable` | 双路失败 / 缺失 / 无法形成有效证据 |

失败、缺失、外语排除、回声排除 **不得**计为 `stable_empty`。

### 5.2 `text_evidence_state`（必须新增）

| 值 | 定义 |
|----|------|
| `all_empty` | 所有可用稳定家族均为 `stable_empty`，且不存在 `stable_text` |
| `single_text` | 恰好一个 `stable_text`，其余可靠家族为 `stable_empty` |
| `consensus_text` | ≥2 个 `stable_text` 进入同一无害等价簇，无 strict semantic conflict；若第三家族也是 `stable_text` 必须等价 |
| `strict_conflict` | ≥2 个 `stable_text` 对同一命题明确对立（要/不要、有/没有等） |
| `divergent_text` | 多个 `stable_text` 不一致但未达严格对立 |
| `insufficient` | 无法形成稳定文本结构 |

继续输出：`too_short / inaudible / audible / borderline / failed`。

## 7. Silero VAD 接入规格

### 7.1 目的与边界

- 输入：当前已有切割后的 wav（与 Sample 音频引用一致）。
- 输出：该 wav **内部**是否存在 speech，以及占比/时长统计。
- **禁止**用 Silero 结果重新切段或改写上游音频路径。

### 7.2 参考实现（`silero-vad-master/`）

优先复用官方 API 语义（包或 vendored 代码均可，但生产入口必须是本仓库算子）：

```python
from silero_vad import load_silero_vad, read_audio, get_speech_timestamps
model = load_silero_vad()  # 或 onnx=True
wav = read_audio(path)     # 默认 16k
speech_timestamps = get_speech_timestamps(wav, model, return_seconds=True)
```

工程约束：

- 采样率：官方支持 8k / 16k；本项目统一 **重采样到 16k** 再推理（与多数 telephony PCM 一致）。
- 运行时：优先 `onnxruntime`（CPU 友好）；若环境已有 torch，允许 JIT，但配置中固定一种并写入 lineage。
- 依赖：`torch`/`torchaudio` 或 `onnxruntime` + 音频 I/O（soundfile / ffmpeg）；与现有工程依赖冲突时优先不污染全局 ASR 环境，可用独立 venv 或懒加载。
- 模型权重：使用 `silero-vad-master/src/silero_vad/data/` 内置 onnx/jit，或配置显式路径；写入 `vad_model_digest`。
- **不得** `pip install` 后在算子里静默从外网拉模型作为唯一路径；离线可复现。

### 7.3 输出字段（写入 sample.quality 或约定侧车）

必须：

```text
vad_status                 # success | failed
vad_speech_state           # present | absent | uncertain | failed
speech_ratio               # float 0~1
speech_duration_ms         # int
longest_speech_ms          # int
speech_segment_count       # int
speech_prob_max            # float，可选但建议
speech_prob_mean           # float，可选但建议
vad_model_digest           # str
vad_config_version         # str，如 silero_vad_v1
```

### 7.4 判定（阈值必须配置化，禁止写死在代码）

`configs/quality/silero_vad_v1.yaml` 初值示例（实验值，最终以人审标定）：

```yaml
silero_vad:
  sample_rate: 16000
  onnx: true
  min_speech_ratio_present: 0.10
  max_speech_ratio_absent: 0.02
  min_speech_duration_ms: 120
  # 透传 get_speech_timestamps 的官方参数（threshold, min_speech_duration_ms 等）按需暴露
```

逻辑：

```text
speech_ratio >= present_threshold AND speech_duration_ms >= minimum
  → present
speech_ratio <= absent_threshold
  → absent
其余 → uncertain
vad 推理失败 → vad_status=failed, vad_speech_state=failed
```

失败不得伪造 `absent`/`present`；下游按 `acoustic_state=failed` / hardcase 处理。

## 8. EfficientAT 接入规格

### 8.1 职责

不做转写；判断当前 wav 主要声音事件类型。关注（AudioSet 标签名，见 `EfficientAT-main/metadata/class_labels_indices.csv`）：

| 业务桶 | 建议聚合的 AudioSet display_name（初版） |
|--------|------------------------------------------|
| speech | `Speech`；可选加权 `Male speech...` / `Female speech...` / `Child speech...` |
| conversation | `Conversation` |
| speech_babble | `Hubbub, speech noise, speech babble`；可选 `Chatter` / `Crowd` |
| environment_noise | `Environmental noise`；以及交通/室外等可配置扩展 |
| music | `Music` |
| vehicle | `Vehicle`；可选 `Traffic noise, roadway noise` / `Engine` |
| mechanical | `Mechanical fan` 等可配置 mechanical 集合 |
| silence_tag | `Silence`（辅助，不单独替代 energy/VAD） |

默认预训练模型建议：`mn10_as` 或 `dymn10_as`（见 `EfficientAT-main/README.md` / `inference.py`）。在配置中固定 `model_name`，写入 digest。

推理参考（不得把 `EfficientAT-main/inference.py` 直接当生产 CLI）：

- 波形 → Mel（`AugmentMelSTFT`，默认 sr=32000, win=800, hop=320, n_mels=128）
- 模型输出 logits → `sigmoid` → 527 类概率
- 从配置的 label 索引表取分并聚合

### 8.2 不全量：候选触发（任一即跑）

1. `text_evidence_state=all_empty` AND `energy_state != inaudible`
2. `text_evidence_state=single_text`
3. `text_evidence_state=consensus_text` AND `vad_speech_state != present`
4. `text_evidence_state=divergent_text`
5. `text_evidence_state=strict_conflict` AND `vad_speech_state=absent`
6. 关键短回答 AND `vad_speech_state != present`

非候选样本：`efficientat_status=skipped`，相关概率字段为空/缺失，`audio_event_state` 可由 VAD+energy 降级推导或标 `unknown`（规则写进 `acoustic_evidence_v1`）。

### 8.3 输出字段

```text
efficientat_status           # success | failed | skipped
speech_prob
conversation_prob
speech_babble_prob
environment_noise_prob
music_prob
vehicle_prob
mechanical_prob
top_k_labels                 # 建议保留 top10 [{name, prob}] 便于审计
efficientat_model_name
efficientat_model_digest
efficientat_config_version
audio_event_state            # 见 §9
```

### 8.4 工程注意

- EfficientAT 默认 fp16 CUDA；CPU float32 可用但慢。配置 `device: cuda|cpu`。
- 权重从 GitHub Releases 自动下载的行为**必须可关闭**；生产使用本地权重目录 + 配置路径。
- 将 `EfficientAT-main` 作为 vendored 依赖时：算子内用明确 `sys.path` 或包装模块，避免污染包名；不要要求用户手工 `cd EfficientAT-main && python inference.py`。
- FFmpeg / librosa 依赖与现有音频解码路径对齐；优先复用工程已有读 wav 能力，再喂 numpy/torch。

## 9. `audio_event_state`

五态 + failed：

```text
non_speech_environment
human_background
speech_like
mixed
unknown
failed
```

| 状态 | 含义 |
|------|------|
| `non_speech_environment` | 环境/机械/车辆等非语音为主，speech/conversation/babble 弱 |
| `human_background` | babble / conversation 明显 → **疑似人声背景污染**；无 speaker verify 不得当确认串音 |
| `speech_like` | Speech 明显，无强烈 babble/environment |
| `mixed` | speech + noise/babble/music 并存 |
| `unknown` | 证据不清 |
| `failed` | 推理失败 |

阈值全部进入 `configs/quality/efficientat_v1.yaml` / `acoustic_evidence_v1.yaml`。

## 10. `acoustic_state` 聚合

五态 + failed：

```text
silence
non_speech_noise
speech_supported
human_noise_suspected
uncertain
failed
```

| acoustic_state | 规则 |
|----------------|------|
| `silence` | `energy_state=inaudible` AND `vad_speech_state=absent`（无需 EfficientAT） |
| `non_speech_noise` | `vad_speech_state=absent` AND `audio_event_state=non_speech_environment` |
| `speech_supported` | `vad_speech_state=present` 且无 `human_background` 强烈矛盾 |
| `human_noise_suspected` | `vad_speech_state=present` AND `audio_event_state=human_background` |
| `uncertain` | VAD uncertain / EfficientAT unknown / 二者冲突 / 证据不足 |
| `failed` | 关键声学算子失败且无法安全降级 |

## 11. Strong Acoustic Veto

仅对 `silence` / `non_speech_noise`：

> ASR 是否有字都不能改变「无真实 speech 支撑」的事实。

因此：多家族同文也可被否决出 gold，进入 `environment_noise`，并标记 hallucination。

## 12. 五分类决策（优先级与矩阵）

主体顺序保持：

```text
voicemail → semantic_risk → environment_noise → gold_candidate → hardcase
```

实现上建议按 **text_evidence_state × acoustic_state** 矩阵落地（与 033 §33 一致），并插入 strong veto / voicemail 短路。

### 12.1 核心决策矩阵

| ASR 结构 | silence | non_speech_noise | speech_supported | human_noise_suspected | uncertain |
|----------|---------|------------------|------------------|----------------------|-----------|
| `all_empty` | env/silence | env/background | hardcase (`empty_asr_but_speech_present`) | env/human_noise + review | hardcase (`empty_asr_acoustic_uncertain`) |
| `single_text` | env + hallucination | env + hallucination | hardcase (`single_text_family_supported_speech`) | human_noise 或 critical hardcase | hardcase (`single_text_acoustic_uncertain`) |
| `consensus_text` | env + multi hallucination | env + multi hallucination | gold/high | gold/medium + review | gold/medium + review |
| `strict_conflict` | env + hallucination | env + hallucination | semantic_risk | semantic_risk | semantic_risk |
| `divergent_text` | env + hallucination | env + hallucination | hardcase | hardcase | hardcase |

### 12.2 environment_noise

- **silence**：`acoustic_state=silence`（含 ASR 仍有 stable_text 的情况）→ `noise_kind=silence`；有字时 `hallucination_state != none`。
- **background**：必须 `acoustic_state=non_speech_noise`。删除「`all_empty + audible`」「DNSMOS noisy」作为充分条件。
- **human_noise**（自动条件变严）：

```text
text_evidence_state=single_text
AND acoustic_state=human_noise_suspected
AND 唯一文本不是 critical_short_response
→ environment_noise/human_noise, confidence=medium, needs_review=true
```

含义仅是「疑似背景人声污染」，不是「已确认非目标人声」。

### 12.3 关键短回答保护

配置词表（与现有 critical short 对齐并可配置扩展）：

```text
要/不要/需要/不需要/可以/不可以/行/不行/有/没有/是/不是/嗯/对 …
```

若 `single_text` + `human_noise_suspected` + 关键短回答：

```text
→ hardcase / critical_short_response_unsupported
```

**不得**自动 `environment_noise/human_noise`。

业务优先级：

```text
关键真实语音误杀率
> hallucination Precision
> environment_noise Recall
> hardcase 压缩率
> 处理速度
```

> 宁愿进 hardcase，也不要误删真实「不需要 / 不行 / 没有」。

### 12.4 gold_candidate

自动 gold 最低条件：

```text
text_evidence_state=consensus_text
AND 不存在 family unstable
AND acoustic_state ∉ {silence, non_speech_noise}
```

| 条件 | 结果 |
|------|------|
| + `speech_supported` | gold, confidence=high |
| + `uncertain` | gold, confidence=medium, needs_review=true（最小改动，避免 gold 骤降） |
| + `human_noise_suspected` | gold, confidence=medium, needs_review=true, quality_tag=human_background_suspected（不得仅因 babble 推翻多家族共识） |
| + silence/non_speech_noise | **禁止 gold** → environment_noise + `hallucination_state=multi_family_consensus` |

### 12.5 semantic_risk / voicemail / unstable

- `strict_conflict`：若同时 silence/non_speech_noise → 优先 environment_noise + `hallucination_state=multi_family_divergent`；否则 semantic_risk。
- voicemail：正则命中逻辑不改；若同时 silence/non_speech_noise → 主类仍 voicemail，但 `needs_review=true`, `review_reason=voicemail_acoustic_contradiction`，并记 `voicemail_acoustic_state`。
- `family_unstable`：否决 gold；若同时强非语音 → environment_noise + review；否则 hardcase/`family_unstable`。

### 12.6 `hallucination_state`（非业务类）

```text
none | single_family | multi_family_consensus | multi_family_divergent
```

## 17. 本版本最终原则（实现禁令）

```text
Energy 决定有没有物理声音
Silero 决定有没有 speech evidence
EfficientAT 决定声音更像什么
ASR family 决定文本是否一致
```

必须遵守：

```text
ASR disagreement ≠ noise
ASR agreement ≠ ground truth
audible ≠ speech
Silero speech ≠ target speaker
EfficientAT babble ≠ confirmed crosstalk
short audio ≠ noise
DNSMOS ≠ speech/noise classifier
```

最重要：

> **只有独立声学证据足够强时，才允许否决多个 ASR 的文本共识。**
