## 1. 我想做什么

把「工序一后置分类」这条**一条命令多步骤**入口，从现行 v2.3：

```text
全量 audio_energy → 全量 silero_vad → efficientat_candidates → efficientat → classify(v2.3)
产物：*_five_class_v2_3_min_acoustic_*
```

完整重构为 **按需声学 0922**：

```text
（前置已完成）音频清洗 + 全量 ASR + 转写结果清洗
→ 语音信箱（原始转写）
→ ASR 证据预分流（队列 A—E / 其余 hardcase）
→ 仅对 A—E 按需 Silero VAD
→ 仅对「B 且无人声」按需 audio_energy（严格全零细分）
→ 仅对「A 或 B 且有人声」按需 DNSMOS（只用 SIG 低档）
→ 五类汇总
产物：*_five_class_v2_4_on_demand_acoustic_*
```

核心变化：

1. **分类条件**严格跟简版 0922（命中即结束的 1→9 条 + 噪声子类）。  
2. **计算顺序**严格跟按需声学流程（先 ASR 分流，声学只对候选子集跑）。  
3. **EfficientAT 退出默认主路径**（本版本不作为分类依据；可保留旁路/legacy，不得默认调用）。  
4. **DNSMOS 有限回归**：只服务疑似 Qwen 幻觉与人声噪声两条；分类只用 SIG；BAK/OVRL 可存不设门槛。  
5. **audio_energy 收窄**：只服务静默 / 非静默背景噪声细分，并补 **混合声道前严格全零** 标记。

入口形态尽量不变（`--batch`、家族别名、缺路体检、脚本与 CLI 同一实现），换的是**编排、规则版本、默认产物 stem、决策证据字段**。

## 4. 业务规矩（分类条件 = 简版 0922）

按顺序判定，**命中即结束**。下列条文是需求正文，实现不得发明并行解释。

### 4.1 口径（必须原样落实）

- 分类输入已剔除物理无效、零时长音频。  
- **稳定有字** = 同一家族双跑成功，清洗后非空文本一致。  
- **稳定否定票** = 同一家族双跑成功且最终均为空；原生空、可信规则清洗空均计票，每族只计 1 票。  
- **原生稳定空** = 双跑成功且**模型原始输出均为空**（未经回声/超长等置空）。  
- 「发生过转写」看清洗前原始输出；「否定票」看清洗后最终输出，分别记录。  
- 分歧仅指有效非空文本的实质语义差异；格式差异不算；空/失败/缺失本身不算语义歧义。  
- 缺失不补票；普通 gold 及极性风险至少需要 2 家族稳定证据。语音信箱与疑似 Qwen 幻觉按各自条件。  
- 一致输出「不要」等名单内容**不**触发关键短应答歧义；满足 gold 条件可为 gold。

### 4.2 判定顺序（简版 1→9）

1. 任一路**原始**转写命中语音信箱关键词 + 其他证据任意 → **语音信箱**  
2. 全部配置家族双跑成功 + Qwen 至少一次原始非空 + 其他家族双跑最终均为空 + Silero 有人声 + **SIG 低** + BAK 任意 → **semantic_risk：qwen_hallucination_suspected**  
3. 全部配置家族双跑成功且**全部路次原始输出均为空** + Silero 有人声 + **SIG 低** + BAK 任意 → **噪声：human_noise**  
4. 任一家族双跑不稳定（两文不同、一空一文、仅一次成功）+ 未命中前述 → **hardcase**  
5. ≥2 家族稳定有字 + 同一命题明确相反含义 + 无否定票 + Silero 有人声 + SIG/BAK 任意 → **semantic_risk：polarity_conflict**  
6. ≥2 家族稳定有字 + 关键短应答实质歧义 + 命中名单 + 未构成第 5 条 + 无否定票 + Silero 有人声 + SIG/BAK 任意 → **semantic_risk：critical_polarity_response**  
7a. 全部家族双跑均为**原生稳定空** + Silero 无人声 + **全声道采样值全为 0** + SIG/BAK 任意 → **噪声：silence**  
7b. 全部家族双跑均为**原生稳定空** + Silero 无人声 + **至少一声道存在非零采样** + SIG/BAK 任意 → **噪声：background_suspected**  
8. ≥2 家族稳定同文 + 其余有效非空文本全部同文 + 无否定票 + Silero 有人声 + SIG/BAK 任意 → **gold**  
9. 以上未命中 → **hardcase**

补充硬约束（来自简版执行说明 + 流程注意）：

- 第 2 条不要求 Qwen 双跑同文；只要双跑都成功且至少一次原始有字。因此 **必须在「双跑不稳定 → hardcase」之前提取**（对应流程队列 A），防止漏掉疑似幻觉。  
- 第 2/3 条互斥；第 3 条不能用「清洗后才为空」冒充「均未发生转写」。  
- 第 2 条其他家族否定票：原生空或规则清洗空可，失败/缺失不可。Qwen 原始有字后被清洗为空，仍算发生过转写。  
- SIG 低沿用配置低档定义；未配置或 SIG 缺失/非低档 → **不得**命中第 2/3 条，归 hardcase 并记原因。BAK 不设门槛。  
- 静默判据 = 混合声道前严格全零；**禁止**用 inaudible / 低能量阈值代替。检查失败或结果缺失 → hardcase，不猜子类。

## 5. 计算顺序（按需声学流程）

只调整计算顺序，不改变 §4 条件。实现编排必须可审计地对应下列步骤。

```text
2、先分语音信箱
   命中 → 结束（不跑 VAD / energy / DNSMOS）

3、只用 ASR 证据预分流（顺序匹配）
   A：全家族双跑成功 + Qwen≥1 次原始有字 + 其他家族最终均空
   B：全家族双跑成功 + 全部路次原始均空
   先保留 A/B；其余若有任一家族双跑不稳定 → hardcase（结束）
   C：≥2 稳定有字 + 同一命题明确极性对立 + 无否定票
   D：≥2 稳定有字 + 关键短应答实质歧义 + 命中名单 + 无否定票（且未命中 C）
   E：≥2 稳定同文 + 其余有效非空全部同文 + 无否定票
   剩余 → hardcase（结束；不跑声学）
   说明：A—E 是计算队列，不是最终类别；纯缺失不补票

4、仅对 A—E 计算 Silero VAD
   A：有人声 → 第 5 步；无人声/不可用 → hardcase
   B：无人声 → 第 4.1 步；有人声 → 第 5 步；不可用 → hardcase
   C：有人声 → polarity_conflict；无人声/不可用 → hardcase
   D：有人声 → critical_polarity_response；无人声/不可用 → hardcase
   E：有人声 → gold；无人声/不可用 → hardcase
   C/D/E 到此结束，不跑 energy、DNSMOS
   A/B 有人声只进第 5 步，不跑 energy

4.1、仅「B 且 VAD 无人声」计算 audio_energy（严格全零）
   全声道全零 → silence
   存在非零 → background_suspected
   失败/缺失 → hardcase
   本分支结束，不跑 DNSMOS；其他分支不计算 energy

5、仅「A 或 B 且 VAD 有人声」计算 DNSMOS
   A + SIG 低 → qwen_hallucination_suspected
   B + SIG 低 → human_noise
   SIG 非低/不可用 → hardcase
   分类只用 SIG；BAK/OVRL 可一并保存

6、汇总五类 + 审计字段
```

编排禁令：

- 禁止对全量样本默认跑 Silero / energy / DNSMOS / EfficientAT。  
- 禁止用 EfficientAT 事件态替代本版本第 2/3/7 条。  
- 禁止在分类步骤内「顺便」做音频清洗或 ASR。

建议工程形态（实现可微调，语义不得变）：

```text
prepare/attach（已有）
→ classify 预分流算子或同进程两阶段：
    phase_asr_route → 写 queue_id / early_category
    phase_on_demand_silero（仅 A—E）
    phase_on_demand_energy（仅 B∩no_speech）
    phase_on_demand_dnsmos（仅 (A∪B)∩speech）
    phase_finalize_category
→ export-summary
```

候选选择可用独立算子（类似现有 `*_candidates`），但必须保证：**未入选样本不得被算子改写成假证据**（status=`not_required` / 等价，且 classify 不得误读为失败或成功声学结论）。
