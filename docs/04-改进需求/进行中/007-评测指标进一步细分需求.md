评测指标必须从 CER 升级成“双指标体系”

以后不要再出现：

Base CER = 8.2%
Fine-tune CER = 7.9%
所以模型提升。

对于你的场景，这个结论几乎没有业务意义。

建议形成：

第一层：ASR 基础指标
CER
Deletion Rate
Insertion Rate
Substitution Rate
第二层：业务风险指标

定义四个核心指标：

1. Negation Flip Rate，NFR

不需要 → 需要
不用 → 用
不要 → 要
没有 → 有
不是 → 是

这是最高优先级。

2. False Affirmation Rate，FAR

真实没有肯定意图，但 ASR 生成：

需要
可以
是
有
要
好的

的比例。

3. Noise-to-Affirmation Hallucination Rate，NAHR

环境噪声 / 无有效语音
          ↓
        ASR
          ↓
需要 / 是 / 可以 / 好的

4. Filler-to-Affirmation Error Rate，FAER

例如：

嗯 → 是
嗯 → 需要
啊 → 有
哦 → 好的

所以你最终的模型对比应该长这样：

模型	CER	NFR ↓	FAR ↓	NAHR ↓	FAER ↓
Base					
LoRA-1K					
Full-1K					
LoRA-3K					

这是你这个项目真正有价值的 scoreboard。
