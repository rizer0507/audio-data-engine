## 3. 完整业务口径

### 3.1 公共前置条件 G

两个分支均要求：

1. 当前 selection 配置中的全部模型家族双跑成功，沿用 `all_families_dual_success`。
2. SenseVoice、GLM、Qwen 均为 `stable_text`，存在有效、非空的稳定代表文本，沿用 `three_families_stable_text`。

当前默认为三家族六路：`sensevoice_1/2`、`glm_1/2`、`qwen_1/2`，对应 [现行 selection 配置](../../../configs/selection/zh_asr_five_class_v3.yaml)。家族内稳定性和代表文本选取继续由现有引擎负责。

“全部家族双跑成功”是**全部配置家族**，并非只检查三个指定家族。若以后加入第四家族，该家族失败也会阻断这两个分支；本次保留该既有口径，未来调整须单独变更定义版本。

### 3.2 分支 A：①且②

在 G 成立时，以下条件全部满足：

- 六路成功转写的任一路**原始文本 `route_raw`**命中 `semantic_risk_keywords` 词表任一条目。
- SenseVoice 与 GLM 的 `family_representative` 无害等价。
- Qwen 的 `family_representative` 与 SenseVoice 代表文本不等价，沿用原配置的比较方向。

**不限制文本长度，不要求三族均为单字，也不要求极性相反。** 关键词可以来自任一家族的任一路，不必出现在 SV/GLM 的共同代表文本中。

直接复用 [现有关键词快照](../../../configs/tagging/lexicons/semantic_risk_keywords_1012.yaml)，词表 ID 为 `semantic_risk_keywords`，当前版本为 `semantic_lexicon_zh_v3_snapshot_20261012`。保留现有 `literal/search`、flags 和条目顺序；不要改用 `tag_1` 演示词表，不从活跃语义词表临时重新抽词，不额外做关键词繁简转换或极性推断。

`route_raw` 能力本身不负责校验路次成功，因此必须保留 G，避免失败路次残留原文被当成有效命中。

### 3.3 分支 B：③

在 G 成立时，以下条件全部满足：

- SenseVoice、GLM、Qwen 的稳定代表文本**分别**满足 `single_han_char`。
- SV 与 GLM 不等价。
- SV 与 Qwen 不等价。
- GLM 与 Qwen 不等价。

**三对比较缺一不可。** “三个模型不一致”在本需求中是两两不同，不能实现为“不是三者全相同”。本分支不依赖关键词命中、关键短应答名单或极性冲突。

### 3.4 文本、单字及三态边界

- 比较及单字判断都使用家族稳定代表文本，继续沿用现行 `classify_text` 清洗和代表文本选择，不能临时选另一条路、拼接文本或取最长文本。
- 单字沿用 `single_han_char`：清洗后整段 `len(text) == 1` 且汉字数为 1。数字、字母、“好啊”“好1”不满足；原文“ 好！ ”按现行清洗得到“好”时可以满足。
- 一致与不一致分别复用 `texts_equivalent`、`texts_not_equivalent`，底层沿用现有无害等价。繁简差异、“您/你”等可被判等价，不能仅按字符串 `!=` 认定分歧，也不另设相似度阈值。
- 原生空、清洗后空、失败、缺失、族内不稳定均不能充当异文或单字。保持 `matched / not_matched / unknown` 三态；无法取得代表文本的比较为 `unknown`，`not unknown` 仍为 `unknown`。前置条件明确不满足时，整条 AND 可以是 `not_matched`，不要强制把所有失败样本改成 `unknown`。
- 两个分支按现有三态规则形成 OR；只有确定命中的 rule 才产生自动 tag。分支 A 要求 SG 等价、分支 B 要求 SG 不等价，因此对同一份证据两分支互斥。

概括为以下**业务公式**，实际执行仍遵循三态语义：

```text
G = 全部配置家族双跑成功 AND SV/GLM/Qwen 均 stable_text
A = G AND 任一六路原文命中关键词 AND SV≈GLM AND Qwen≉SV
B = G AND 三族代表文本各一个汉字 AND SV≉GLM AND SV≉Qwen AND GLM≉Qwen
新 tag 自动命中 = A OR B
```

## 7. 验收标准

### 7.1 固定离线规则样例

以下 SV/GLM/Qwen 文本均指各家族双跑稳定后的代表文本；除明确说明外，六路均成功，原文与可比文本一致：

1. `需要贷款 / 需要贷款 / 天气晴朗`：A 命中、B 不命中，新 tag 命中；证明 A 无单字限制。
2. `好 / 好 / 要`：A 命中、B 不命中；保留原“①且②”对单字的支持。
3. `需要贷款 / 需要贷款 / 需要贷款`：两分支均不命中；仅①不足以打 tag。
4. `甲乙 / 甲乙 / 甲丙`：两分支均不命中；仅②不足以打 tag。
5. `甲 / 乙 / 丙`：A 不命中、B 命中，且确认词表未命中；证明③可独立命中。
6. `甲 / 乙 / 乙`、`甲 / 乙 / 甲`、`甲 / 甲 / 乙`：两分支均不命中；分别防止漏掉任一对比较。
7. `您 / 你 / 他`、`對 / 对 / 他`：B 不命中；无害等价不能当成两两异文。其中 `對 / 对 / 他` 的原文“对”命中关键词，且 SG 等价，A 可以命中；B 不命中不代表整个 tag 不命中。
8. `甲 / 乙 / 丙丁`、`甲 / 乙 / 1`：B 不命中；必须三族各为一个汉字。
9. 双跑路次原文 `" 甲！ "` 等经现行清洗形成 `甲 / 乙 / 丙`：B 命中；不得错误按原文长度限制。
10. 任一家族为空、缺路、失败或族内双跑不稳定：不得自动命中新 tag；逐条件及整条三态遵循现有合成规则。增加失败路次残留关键词原文的用例，确认不会绕过 G。
11. 参数化将唯一关键词命中放到六路中的每一路，其余满足 A：A 均可命中；关键词不强绑 SG 代表文本，也不能误用演示词表。可把 SG 四路原文设为“闭 嘴”、Qwen 两路设为“骚 扰”，每次只将指定一路去空格变为“闭嘴”或“骚扰”；清洗后仍保持家族稳定，且只有指定原文命中。

增加 A 分支与旧独立配置的对照：同一固定证据下，对应规则三态及关键证据一致，仅新 tag/rule 身份不同。复用现有测试辅助函数，避免重写家族状态或等价算法作为测试预期。

构造夹具时注意：现有原文读取优先使用 `transcripts[run_id].extra.raw_text`，其次为 `text`，不读取顶层 `raw_text`。若原文与正文分开，应使用 `extra.raw_text`；也可直接把待测原文放在 `text` 中。

### 7.2 库接入与维护验收
