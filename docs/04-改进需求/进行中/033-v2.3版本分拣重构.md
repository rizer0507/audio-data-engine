# **五类分拣规则与决策流程 v2.3_min_acoustic**


| **项**  | **值**                                                                     |
| ------ | ------------------------------------------------------------------------- |
| 版本定位   | 基于 `selection_five_class_v2_2_auto_noise` 的最小改动版                          |
| 建议版本   | `selection_five_class_v2_3_min_acoustic`                                  |
| 修订目标   | 用 `Silero VAD + EfficientAT` 替代 DNSMOS 在“是否有人声 / 是否环境噪声 / 是否人声噪声”上的核心判定职责 |
| 保留骨架   | 五分类、家族四态、audio_energy、hardcase 兜底、互斥出口                                    |
| 新增框架   | `Silero VAD`、`EfficientAT`                                                |
| 暂不引入   | WeSpeaker、pyannote、Brouhaha、额外 diarization                                |
| DNSMOS | 暂保留旁路，不再作为主分类依据                                                           |


---

## **1. 修改原则**

本版本不重构现有业务体系，只解决当前 v2.2 中声学证据目标错位的问题。

保留：

```
多家族 ASR
→ 家族四态
→ audio_energy
→ 五分类
```

修改为：

```
多家族 ASR
→ 家族四态
→ audio_energy
→ Silero VAD
→ EfficientAT（仅候选）
→ 五分类
```

核心原则：

```
audio_energy：回答“有没有声音”
Silero VAD：回答“有没有人类语音”
EfficientAT：回答“主要是什么声音”
ASR：回答“模型听成了什么”
```

不得再使用：

```
ASR disagreement ≈ noise
audible ≈ speech
DNSMOS noisy ≈ environment noise
DNSMOS SIG strong ≈ speech exists
```

---

# **2. 业务出口保持不变**

仍保留五个业务类别：

```
voicemail
semantic_risk
environment_noise
gold_candidate
hardcase
```

出口定义不变：


| **outcome**  | **category** | **含义**             |
| ------------ | ------------ | ------------------ |
| `classified` | 五类之一         | 成功进入业务分类           |
| `excluded`   | `null`       | 音频物理无效 / 全部路次被前置排除 |


禁止新增：

```
manual_annotation
pending_evidence
unknown_class
```

作为第六业务类别。

无法自动决策的样本统一进入：

```
hardcase
```

并记录明确 `hardcase_reason`。

---

# **3. 流水线调整**

现有：

```
quality.audio_energy
→ quality.dnsmos_v2_2_candidates
→ quality.classify
```

建议调整为：

```
quality.audio_energy
→ quality.silero_vad
→ quality.efficientat_candidates
→ quality.efficientat
→ quality.classify
```

DNSMOS 可暂时继续旁路运行：

```
quality.dnsmos
```

但不再参与五分类主决策。

推荐整体：

```
清洗落库
  ↓
Qwen / GLM / SenseVoice 多家族双跑
  ↓
prepared / prepared_asr
  ↓
family evidence aggregation
  ↓
audio_energy
  ↓
Silero VAD
  ↓
EfficientAT candidate selector
  ↓
EfficientAT（仅候选）
  ↓
five_class_v2_3_min_acoustic
  ↓
export-summary / 人审 / Release
```

---

# **4. 家族四态保持不变**

每个 ASR 家族的双跑仍归并为四态：


| **状态**         | **定义**               |
| -------------- | -------------------- |
| `stable_text`  | 两路成功且文本一致 / 仅无害差异    |
| `stable_empty` | 两路成功且清洗后均为空          |
| `unstable`     | 一空一有字、实质冲突、单路成功等     |
| `unavailable`  | 双路失败 / 缺失 / 无法形成有效证据 |


继续保持：

```
失败
缺失
外语排除
回声排除
```

不得作为：

```
stable_empty
```

---

# **5. 文本证据状态**

在家族四态上增加一个轻量聚合字段：

```
text_evidence_state
```

仅用于简化决策逻辑。

## **5.1** `all_empty`

所有可用稳定家族均为：

```
stable_empty
```

且不存在 `stable_text`。

---

## **5.2** `single_text`

恰好一个家族：

```
stable_text
```

其他可靠家族为：

```
stable_empty
```

---

## **5.3** `consensus_text`

至少两个：

```
stable_text
```

进入同一无害等价文本簇，并且不存在：

```
strict semantic conflict
```

若第三个家族也是 `stable_text`，则必须与该簇等价，否则不能视为 `consensus_text`。

---

## **5.4** `strict_conflict`

至少两个 `stable_text` 家族对同一命题存在明确语义对立。

例如：

```
需要 / 不需要
可以 / 不可以
有 / 没有
是 / 不是
```

---

## **5.5** `divergent_text`

多个 `stable_text`：

```
不一致
但又未达到严格语义冲突
```

例如：

```
Qwen: 需要
GLM: 可以
SenseVoice: 好的
```

---

## **5.6** `insufficient`

无法形成稳定文本结构。

---

# **6. audio_energy 保持原职责**

保留：

```
too_short
inaudible
audible
borderline
failed
```

但调整一条规则：

## **6.1** `too_short` **不再自动进入 environment_noise**

原：

```
energy_state=too_short
→ environment_noise/audio_too_short
```

修改为：

```
quality_tag=short_audio
```

然后继续进入正常分类。

原因：

```
嗯
不
对
要
有
```

等真实业务短回答本身可能低于现有时长阈值。

只有：

```
无法解码
文件损坏
0 duration
```

等真正物理无效情况才：

```
outcome=excluded
category=null
```

# **7. 新增 Silero VAD**

## **7.1 目的**

Silero VAD 不重新切割音频。

输入：

```
当前已有切割后的 wav
```

输出：

```
当前 wav 内部是否存在 speech，以及 speech 占比
```

---

## **7.2 建议字段**

```
vad_status
vad_speech_state

speech_ratio
speech_duration_ms
longest_speech_ms
speech_segment_count

speech_prob_max
speech_prob_mean
```

其中：

```
vad_status:
success
failed
```

建议：

```
vad_speech_state:
present
absent
uncertain
failed
```

---

## **7.3 初版判定原则**

阈值不要在代码中写死，必须配置化。

示例：

```
silero_vad:
  min_speech_ratio_present: 0.10
  max_speech_ratio_absent: 0.02
  min_speech_duration_ms: 120
```

逻辑：

```
speech_ratio >= present_threshold
AND
speech_duration_ms >= minimum
→ present
```

```
speech_ratio <= absent_threshold
→ absent
```

其余：

```
uncertain
```

注意：

这些只是初始实验阈值，最终需要根据人工标注数据确定。

---

# **8. 新增 EfficientAT**

## **8.1 职责**

EfficientAT 不用于转写文本。

它用于判断：

```
当前 wav 主要属于哪类声音事件
```

重点关注：

```
Speech
Conversation
Hubbub / speech noise / speech babble
Environmental noise
Music
Vehicle
Mechanical sound
```

---

## **8.2 不全量执行**

EfficientAT 只跑候选样本。

触发条件满足任一即可：

### **候选 1**

```
text_evidence_state=all_empty
AND
energy_state != inaudible
```

### **候选 2**

```
text_evidence_state=single_text
```

### **候选 3**

```
text_evidence_state=consensus_text
AND
vad_speech_state != present
```

### **候选 4**

```
text_evidence_state=divergent_text
```

### **候选 5**

```
text_evidence_state=strict_conflict
AND
vad_speech_state=absent
```

### **候选 6**

```
关键短回答
AND
vad_speech_state != present
```

---

# **10. audio_event_state**

建议只保留五个状态：

```
non_speech_environment
human_background
speech_like
mixed
unknown
```

以及：

```
failed
```

---

## **10.1** `non_speech_environment`

表示主要证据指向：

```
环境声
机械声
车辆声
其他非语音声音
```

同时：

```
speech / conversation / babble
```

证据较弱。

---

## **10.2** `human_background`

表示：

```
speech_babble
conversation
```

明显。

该状态表示：

```
有人声背景污染
```

但由于当前没有 Speaker Verification：

> 不得自动解释成“确认是非目标客户人声”。

---

## **10.3** `speech_like`

表示：

```
Speech
```

信号明显，但没有强烈 babble / environment evidence。

---

## **10.4** `mixed`

同时有：

```
speech
+
noise / babble / music
```

等混合特征。

---

## **10.5** `unknown`

证据不清晰。

---

# **11. 综合声学证据**

为最小化改动，只增加：

```
acoustic_state
```

建议五态：

```
silence
non_speech_noise
speech_supported
human_noise_suspected
uncertain
```

以及：

```
failed
```

---

# **12. acoustic_state 规则**

## **12.1** `silence`

```
energy_state=inaudible
AND
vad_speech_state=absent
```

无需 EfficientAT。

---

## **12.2** `non_speech_noise`

必须满足：

```
vad_speech_state=absent
AND
audio_event_state=non_speech_environment
```

这是：

```
environment_noise/background
```

最重要的强证据。

---

## **12.3** `speech_supported`

满足：

```
vad_speech_state=present
```

且没有：

```
audio_event_state=human_background
```

强烈矛盾。

---

## **12.4** `human_noise_suspected`

满足：

```
vad_speech_state=present
AND
audio_event_state=human_background
```

注意：

当前没有 speaker verification。

因此它只能表示：

```
疑似人声串音 / 人声背景污染
```

不能自动升级为：

```
confirmed crosstalk
```

---

## **12.5** `uncertain`

包括：

```
VAD uncertain
EfficientAT unknown
VAD 与 EfficientAT 冲突
```

等情况。

---

# **13. 五分类优先级**

建议继续保持原有主体顺序：

```
voicemail
→ semantic_risk
→ environment_noise
→ gold_candidate
→ hardcase
```

但增加一个最小的：

```
strong acoustic veto
```

主要防止：

```
噪声导致多个 ASR 同时产生相同 hallucination
→ 被误判 gold
```

---

# **14. Strong Acoustic Veto**

只对两类强声学状态执行：

```
silence
non_speech_noise
```

如果命中：

```
silence
或
non_speech_noise
```

则：

```
ASR 是否有字都不能改变“无真实 speech 支撑”的事实。
```

---

# **15. environment_noise**

保留原顶层类别：

```
environment_noise
```

`noise_kind` 建议收敛为：

```
silence
background
human_noise
```

当前版本不再自动输出：

```
crosstalk
```

因为没有 speaker verification。

---

# **16. silence**

自动进入：

```
category=environment_noise
noise_kind=silence
```

条件：

```
acoustic_state=silence
AND
text_evidence_state=all_empty
```

---

如果：

```
acoustic_state=silence
AND
ASR 有 stable_text
```

仍进入：

```
environment_noise
noise_kind=silence
```

同时：

```
hallucination_state != none
```

---

# **17. background**

自动：

```
category=environment_noise
noise_kind=background
```

必须：

```
acoustic_state=non_speech_noise
```

不再使用：

```
all_empty + audible
```

作为充分条件。

也不再使用：

```
DNSMOS noisy
```

作为核心噪声证据。

---

# **18. human_noise**

为了最小改动，可继续保留：

```
noise_kind=human_noise
```

但自动条件变严格。

原规则：

```
>=2 stable_empty
+
恰好1 stable_text
+
audible
→ human_noise
```

删除。

新规则：

```
text_evidence_state=single_text
AND
acoustic_state=human_noise_suspected
AND
唯一文本不是 critical_short_response
```

建议：

```
category=environment_noise
noise_kind=human_noise
confidence=medium
needs_review=true
```

由于目前没有 speaker verification：

```
human_noise
```

只能表示：

```
疑似背景人声污染
```

而不是：

```
已确认非目标人声
```

---

# **19. 关键短回答保护**

对于以下配置词表：

```
要
不要
需要
不需要
可以
不可以
行
不行
有
没有
是
不是
嗯
对
```

等关键业务短应答：

如果：

```
text_evidence_state=single_text
AND
acoustic_state=human_noise_suspected
```

不得自动：

```
environment_noise/human_noise
```

必须进入：

```
hardcase
hardcase_reason=critical_short_response_unsupported
```

# **20. ASR Hallucination 字段**

新增：

```
hallucination_state
```

这不是业务类别。

取值：

```
none
single_family
multi_family_consensus
multi_family_divergent
```

---

## **20.1 single_family**

```
强非语音声学证据
+
只有一个 stable_text family
```

---

## **20.2 multi_family_consensus**

```
acoustic_state in [silence, non_speech_noise]
+
text_evidence_state=consensus_text
```

这类样本非常重要：

> 多个 ASR 对非语音声音产生相同 hallucination。

应作为后续 ASR 优化重点数据。

---

## **20.3 multi_family_divergent**

```
强非语音声学证据
+
多个 ASR 有不同文本
```

---

# **21. gold_candidate**

原：

```
>=2 stable_text 同文
→ gold_candidate
```

增加一个最低声学保护。

自动 gold 必须：

```
text_evidence_state=consensus_text
AND
不存在 family unstable
AND
acoustic_state != silence
AND
acoustic_state != non_speech_noise
```

---

## **21.1 推荐 high confidence**

```
consensus_text
AND
acoustic_state=speech_supported
AND
不存在 unstable
```

→

```
gold_candidate
confidence=high
```

---

## **21.2 声学不确定**

```
consensus_text
AND
acoustic_state=uncertain
```

建议：

```
gold_candidate
confidence=medium
needs_review=true
```

这是“最小改动”策略。

不直接把所有 acoustic uncertain 打入 hardcase，避免 gold 数量骤降。

---

## **21.3 强非语音否决 gold**

如果：

```
consensus_text
AND
acoustic_state=silence/non_speech_noise
```

禁止 gold。

进入：

```
environment_noise
```

并：

```
hallucination_state=multi_family_consensus
```

---

# **22. semantic_risk**

保持原逻辑：

```
text_evidence_state=strict_conflict
→ semantic_risk
```

但增加一条：

如果同时：

```
acoustic_state=silence
或
acoustic_state=non_speech_noise
```

则优先：

```
environment_noise
```

并：

```
hallucination_state=multi_family_divergent
```

因为此时不同 ASR 文本都缺乏真实 speech 支撑。

其余情况下：

```
semantic_risk
```

保持原规则。

---

# **23. voicemail**

为最小化改动，暂不重构 voicemail 逻辑。

仍：

```
有效 route 命中 voicemail regex
→ voicemail
```

但建议新增审计字段：

```
voicemail_acoustic_state
```

如果：

```
voicemail
+
acoustic_state=silence/non_speech_noise
```

则：

```
needs_review=true
review_reason=voicemail_acoustic_contradiction
```

暂不改变主类别，避免扩大本次改造范围。

建议增加：

# **25. all_empty 决策**

当：

```
text_evidence_state=all_empty
```

执行：

```
acoustic_state=silence
→ environment_noise/silence
```

```
acoustic_state=non_speech_noise
→ environment_noise/background
```

```
acoustic_state=speech_supported
→ hardcase/empty_asr_but_speech_present
```

```
acoustic_state=human_noise_suspected
→ environment_noise/human_noise
  confidence=medium
  needs_review=true
```

```
acoustic_state=uncertain
→ hardcase/empty_asr_acoustic_uncertain
```

删除原：

```
all_empty + audible + DNSMOS unavailable
→ background
```

---

# **26. single_text 决策**

当：

```
text_evidence_state=single_text
```

执行：

### **非语音噪声**

```
acoustic_state=silence/non_speech_noise
→ environment_noise
→ hallucination_state=single_family
```

### **Speech Supported**

```
acoustic_state=speech_supported
→ hardcase
hardcase_reason=single_text_family_supported_speech
```

因为：

> 当前不能确定是单模型正确还是其他模型漏识别。

### **Human Noise Suspected**

普通文本：

```
→ environment_noise/human_noise
confidence=medium
needs_review=true
```

关键短回答：

```
→ hardcase/critical_short_response_unsupported
```

### **Uncertain**

```
→ hardcase/single_text_acoustic_uncertain
```

---

# **27. consensus_text 决策**

当：

```
text_evidence_state=consensus_text
```

执行：

### **强非语音声学证据**

```
silence/non_speech_noise
→ environment_noise
→ hallucination_state=multi_family_consensus
```

### **Speech Supported**

```
→ gold_candidate
```

### **Human Noise Suspected**

由于没有 Speaker Verification：

```
→ gold_candidate
confidence=medium
needs_review=true
quality_tag=human_background_suspected
```

注意：

不能因为 EfficientAT 认为存在 babble 就推翻多个稳定 ASR 的文本共识。

### **Uncertain**

```
→ gold_candidate
confidence=medium
needs_review=true
```

以最小化影响现有 gold 产量。

---

# **43. 本版本最终原则**

```
Energy 决定“有没有物理声音”
```

```
Silero 决定“有没有 speech evidence”
```

```
EfficientAT 决定“声音更像什么”
```

```
ASR family 决定“模型文本是否一致”
```

最终：

```
声学证据
+
文本证据
```

联合决策。

必须遵守：

```
ASR disagreement ≠ noise
```

```
ASR agreement ≠ ground truth
```

```
audible ≠ speech
```

```
Silero speech ≠ target speaker
```

```
EfficientAT babble ≠ confirmed crosstalk
```

```
short audio ≠ noise
```

```
DNSMOS ≠ speech / noise classifier
```

以及最重要的一条：

> **只有独立声学证据足够强时，才允许否决多个 ASR 的文本共识。**
