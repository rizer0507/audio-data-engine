# 041 父源／片段数据契约与历史兼容说明

日期：2026-10-14（修订：声道 ch0／16k／EOF 纳入）。对应需求：`041-源PCM入库后FSMN-VAD切段需求理解.md`。

## 1. 字段映射

| 语义 | Sample 落点 | 说明 |
|------|-------------|------|
| 源音频 ID | `labels.source_audio_id` | 切段前父样本 `id` |
| 父 PCM 摘要 | `labels.source_pcm_sha256` / `parent_pcm_sha256` | 仅血缘，不作缓存／仓库工作身份 |
| 规范音频 | `labels.normalized_audio_path` + `normalized_audio_sha256`；`audio.normalized_16k` | 与 VAD／裁切同一份 |
| 片段 ID | `Sample.id` = `labels.segment_id` | `seg_` + 稳定哈希 |
| 工作内容身份 | `Sample.sha256` = `labels.original_audio_sha256` = `segment_pcm_sha256` | **片段** PCM 体哈希 |
| 边界 | `vad_start_ms` / `vad_end_ms` / `clip_*_sample` | 毫秒为模型边界；采样为实际裁切 |
| 结束原因 | `vad_end_reason` / `labels.vad_end_reason` | `vad_endpoint` 或 `eof_fallback` |
| 推断终点 | `vad_inferred_end_ms` | 仅 EOF；模型未返回的 end 不得伪造 |
| 源采样率 | `labels.source_sample_rate` / `quality.source_sample_rate` | **真实输入**；与规范率分字段 |
| 规范采样率 | `labels.normalized_sample_rate` / `quality.target_sample_rate` | 固定 16000 |
| 声道策略 | `source_channels` / `selected_channel=0` / `channel_policy` | 多声道只取 ch0 |
| 采样率来源 | `sample_rate_source` | `file_header` / `source_config` / `default_convention` |
| 音频键 | `audio.resampled_16k` | 片段 WAV（16 kHz mono PCM16） |
| 父源回听 | `audio.parent_raw` | 未切分录音路径 |

源处理侧车：`runs/<run>/vad_source_results/<source_audio_id>.json`  
规范化汇总：`runs/<run>/normalize_summary.json`（含 8k 告警清单）

## 2. 身份与防串规则

- 兄弟片段共享 `source_audio_id` 与父 PCM 哈希，但 **不得** 共享 `original_audio_sha256`。
- 算子缓存键仍用 `sample.sha256` → 按片段隔离。
- 仓库去重按工作身份（片段哈希）；标注回填按 `sample_id + original_audio_sha256`。
- 旧整段包（父哈希）无法匹配新片段哈希，会被拒绝。

## 3. 声道与采样率策略（已确认）

- 单声道直接处理；多声道有头文件 → 只取第 0 声道。
- 无头 PCM 默认 `channels=1`、`source_sample_rate=16000`（`default_convention`）；可信配置可声明其他值（`source_config`）。
- 声明多声道时解交织后取 ch0；长度不能整除声道数则报错（禁止交织当单声道）。
- 真实 8 kHz：控制台 + 日志 + `normalize_summary` 明显提示，再重采样到 16 kHz；源率与规范率分字段。

## 4. EOF 补尾（049 已取代本节旧规则）

> **已被 [049](./049-FSMN-VAD与分身实时服务完全对齐.md) 取代**：分身 `send_end_result=true` 时，pending 在客户端 end 裁到源 PCM 末尾并发布，**不再**套用统一 1 秒门限，也不再丢弃 EOF 补尾。下列 041 原文仅作历史记录。

- ~~`include_eof_fallback=true`（默认）。~~ → 现为 `send_end_result=true`。
- ~~≥1000 ms 保留 / <1000 ms 丢弃。~~ → 取消统一 1s 门限。
- 无有效 start／解码失败／VAD 失败：不整文件兜底（此项仍有效）。

## 5. 产物与入口

- `cleaned_<batch>.*` = 保留片段 Manifest（含合格 EOF 段）。
- ASR／聚合／归类／033 入口不变，消费片段行。
- 训练分组：`source_audio_id` + 父 PCM 哈希。

## 6. 历史兼容

| 对象 | 行为 |
|------|------|
| 历史整段 `cleaned_*` | 仍可读（无 `is_vad_segment`） |
| 历史整段标注包 | 不能回填到新片段 |
| 已冻结仓库 | 不覆盖；版本变更新快照 |
| 切段／规范化版本变更 | 新 `segment_id`，旧缓存不复用 |
